# Server Manager 0.7.0-beta.30

## Beta29 Minecraft 로그인 차단 수정

Beta29에서 추가한 endpoint 큐의32항목 제한이, 정상 로그인 중 들어오는 작은 TCP 조각들을 과적체로 오판해 `ENDPOINT_BACKPRESSURE`로 연결을 종료했습니다. 실제 운영에서는 큐가 약103~114KiB이고 직전 쓰기가2~4ms 전인데도 접속을 끊는 현상이 확인됐습니다.

작은 조각을 최대32KiB 묶음으로 합쳐 항목 수에 의한 오판을 제거했습니다.512KiB/역할16MiB 바이트 예산,10초 쓰기 기한, 느린 접속 격리와 정상 EOF drain은 유지합니다. 실제 바이트 상한에 걸리는 경우에는 `limitCause`, `queuedChunks`, 필요한 바이트와 최근 쓰기 시간을 추가 기록합니다.

## 적용

**중계와 게임 실행기의 GAME_HOST를 beta.30으로 교체해야 합니다.** 실행기 제어 계층만 바뀌고 기존 상주 서비스가 살아 있으면 수정되지 않습니다. 게임을 정상 종료한 뒤 업데이트를 적용하고 다시 시작하세요.

## 검증

수정 전1000×256B 작은 조각 시험이32번째에서 실패하는 것을 재현했습니다. 수정 후에는 전체256001바이트가 정확히 보존되고 예산이 회수됐습니다. 관련69개 테스트에서 느린 플레이어/게임 백엔드의 격리, 다른 접속 유지,512KiB 응답 직후 EOF, UDP/음성/상주 서비스 회귀가 통과했습니다. 통합에서도69개와 보안11개·실행기 설치·TS/Vite·JAR 빌드가 통과했습니다. 패키징·서명 결과는 릴리즈 브랜치 노트에 기록합니다.

이번 수정은 확인된 beta29 로그인 회귀를 해결합니다. 그 이전의 하루1~2회 동시 끊김 원인은 별개로 미확정입니다. 전체 suite/다른OS 실기/게시 자산 재다운로드 해시 비교는 생략합니다.
