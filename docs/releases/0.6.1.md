# 0.6.1 — 릴리즈 선택 수동 업데이트

관리 웹의 **시스템 → 앱 업데이트 → 릴리즈를 선택해서 수동 업데이트**에서 목록을 새로고침하고 원하는 릴리즈를 선택해 설치할 수 있습니다. 안정판과 베타를 함께 표시하며 베타는 별도 동의가 필요합니다. 자동 업데이트 설정은 유지됩니다.

- 공개 릴리즈 중 현재보다 높은 버전만 설치합니다. 현재 버전 이하, 시작 검증 실패 이력, 필수 업데이트 파일 누락은 선택할 수 없습니다.
- 소유자 권한과 최근 패스키 인증이 필요합니다. 선택한 버전은 게시자 서명·해시·버전·호환성 검증 후 기존 안전 재시작 절차로 적용합니다. 진행 상황과 로그는 기존 패널에서 확인합니다.
- 목록은 최근 공개 GitHub 릴리즈 100개를 조회합니다. 설치 앱에서 지원하며 자동 확인은 기존 안정판/베타 채널 규칙을 유지합니다.
- 이 안정판은 0.6.0 기반의 업데이트 UI 변경입니다. 신규 Qwen 프로젝트 하네스는 별도 `0.7.0-beta.1`에 있습니다. 먼저 0.6.1로 업데이트한 다음 목록에서 해당 베타를 선택해 시험할 수 있습니다. 낮은 버전으로 되돌리려면 별도 설치 파일이 필요합니다.

Mac에서 관련 백엔드 테스트 18개, 브라우저 선택·동의·취소·설치 요청 시나리오 1개, 프런트엔드·JAR 빌드와 임시 부트스트랩의 서명 업그레이드·변조 거부·롤백·프로필 보존을 확인했습니다. 전체 테스트와 다른 운영체제 검증은 사용자 지시로 생략했습니다. 운영 앱은 자동 교체하지 않았습니다.
