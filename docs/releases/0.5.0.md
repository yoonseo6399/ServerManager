# Server Manager 0.5.0

- Qwen을 성능이 좋은 서버 실행기에서 실행할 수 있습니다. 해당 컴퓨터의 실행기에 `RUNNER_LLM_ENABLED=true` 또는 데이터 폴더의 `llm-enabled`(내용 `true`)를 설정하고 Ollama와 모델을 준비하면, Discord `/local-llm`이 연결된 실행기로 요청을 보내고 답변에 실행기 이름을 표시합니다. 허용한 실행기가 없으면 기존처럼 관리 앱 컴퓨터에서 실행합니다. 질문은 기존 인증된 실행기 연결로만 전달되고, Ollama 주소와 모델 태그는 실행기 컴퓨터의 환경변수로만 정합니다.
- Discord 음악: 한 곡 반복(`/music repeat [enabled]`)을 추가했습니다. 끝까지 재생된 곡을 다시 재생하며 건너뛰기는 다음 곡으로 넘어갑니다.
- 음악 패널에 `📻 자동재생 ON/OFF`, `🔂 한 곡 반복 ON/OFF` 버튼을 추가했습니다. 자동재생은 완주 기록 통계로 곡을 고르며 인기 곡의 가중치 보너스는 최대 6%입니다.
- 저장 플레이리스트, 대기열 항목 삭제·페이지, 완주 통계 기반 랜덤 자동재생, 에이전트 조율 상태판, Modrinth 미확인 모드 경고 처리 등 main에 있던 변경을 모두 포함합니다.
- 0.4.14의 Qwen 일반 대화, 실행기 TCP 중계, 뒤로가기 지원과 실행 중 모드 조회를 유지합니다.

사용 방법: `docs/luonnotar-agent.md`, `docs/discord-music.md`, `docs/tcp-relay-runner.md`.
실제 Qwen 추론·Discord 음성/실연동·실행기 경유 Qwen은 이 환경에서 검증하지 않았습니다. 개발 PC(Windows)에서는 POSIX 권한·심볼릭 링크·Java 경로에 의존하는 기존 테스트가 실패하며 전체 테스트는 릴리즈 CI에서 실행됩니다.
