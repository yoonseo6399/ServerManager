# Server Manager 0.4.7

- 원격 Minecraft 서버에서도 강제 종료를 지원합니다. 정상 종료가 멈춘 STOPPING 상태에서도 사용할 수 있습니다.
- 서버 관리 권한과 현재 실행기의 서버 사용 허용을 확인하며, 최신 연결에서 확인한 Minecraft PID와 일치하는 프로세스와 하위 프로세스만 종료합니다. 오래된 연결·PID로 다른 실행을 종료하지 않습니다.
- UI 확인창에 저장되지 않은 변경의 손실 가능성을 표시합니다. 구버전 실행기는 강제 종료 버튼을 비활성화하고 0.4.7 업데이트를 안내합니다. 중앙과 실행기를 함께 업데이트하세요.
- 프로세스의 실제 종료 확인, 종료 메타데이터 기록과 파일 인계 절차를 유지합니다. 강제 종료 요청만으로 잠금이나 미전송 상태를 해제하지 않습니다. Discord 종료 사유에도 강제 종료를 구분합니다.
- Sable Query 포트 분리와 인증 UDP 중계 등 0.4.6 변경을 포함합니다. Minecraft 청크 언로드 반복 문제 자체를 해결하는 패치는 아닙니다.
