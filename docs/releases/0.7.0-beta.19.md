# 0.7.0-beta.19 — Pi 명령 실행 Bash 통합

관리 앱을 업데이트하세요. 추론 실행기의 기존 Beta18 기능과 호환됩니다. stable/latest는0.6.3을 유지하는 베타 릴리즈입니다.

- Pi의 명령 실행 도구를 OWNER용 native `bash`로 통일했습니다. 기존 제한형 `sh`가 `cd`를 거부하여 정상 git 조회까지 중단시키던 혼선을 없앴습니다. READ/EDIT 역할에는 임의 셸 권한을 추가하지 않습니다.
- 과거 대화의 sh 호출이 현재 도구가 아님을 안내합니다. 제거된 sh 호출은 미실행 입력 오류로 처리하며 같은 요청에서 bash로 수정할 수 있습니다. 실제 독립 위험 검토 거부·사용자 거절·승인 만료·권한 검사 실패의 우회 방지는 유지합니다.
- 독립 위험 검토, 실행 파일 내용 검사, 프로젝트 밖/UNKNOWN 명령과 push·PR의 명시적 승인, 실행 명령·출력·diff 기록은 그대로입니다. Bash는 OS 사용자 권한으로 실행되며 OS 샌드박스가 아닙니다.

검증: 실제 고정 Pi SDK 기반 관련25개 테스트 통과. 미등록 sh 오류 후 bash로 수정하여 `cd && git status && git remote -v`를 명시 승인 뒤 실행하고 출력·세션 재개를 확인했습니다. 위험 스크립트의 내용 전달·거부, 외부 접근 승인, 사용자 거절·중단 회귀를 포함합니다. 모델 응답은 결정적 fixture이며 이번 변경에서 실제27B/운영 Discord 사용자 시험은 하지 않았습니다.

전체 테스트와 다른 OS 실기 검증은 사용자 요청으로 생략합니다. CI에서 프런트·JAR·설치 패키징·격리 부트스트랩·서명·게시를 진행합니다. 운영 앱·게임·실행기를 자동 교체하거나 재시작하지 않습니다. 게시 후 릴리즈 파일 재다운로드·해시 대조도 사용자 요청으로 생략합니다.
