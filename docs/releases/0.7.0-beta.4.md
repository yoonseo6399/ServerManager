# Server Manager 0.7.0-beta.4

Qwen 에이전트의 다단계 작업·문맥 관리·Discord 출력을 개선한 테스트용 베타입니다. stable 최신 버전은 0.6.3으로 유지합니다.

## Qwen
- 도구 결과를 검토하고 수정·재검증을 이어가는 다단계 실행 지시를 추가했습니다. 도구 실행 자체를 완료로 판단하지 않으며 최대 12턴입니다.
- 모델 답변은 Markdown 일반 메시지, 턴 상태·승인·요약은 임베드로 분리했습니다. 실제 Thinking만 ‘…’로 감싸 점진적으로 표시하고 중지 버튼으로 현재 작업을 중단합니다.
- 긴 답변·실행 로그는 여러 메시지로 이어 보냅니다. 장시간 명령은 턴 스레드에 실행 중 로그를 전달합니다. 전체 요청 JSON 첨부를 제거했습니다.
- 긴 도구 결과는 독립된 도구 없는 Qwen 세션이 요약하여 다음 모델 턴과 임베드에 전달합니다. 짧은 결과는 종료 코드를 포함한 간략 결과를 사용합니다.
- 프로젝트별 최초 동의 후 일반 Gradle build/test/check/assemble을 자동 승인 모드에서 재사용합니다. 빌드 설정·wrapper·빌드 로직 변경 시 재승인하며 임의 셸·배포 명령의 승인은 유지합니다.
- 루오노타르·루오·봇 멘션을 명시적 호출로 인식하고, 후속 질문 판별에 최근 대화를 전달합니다. 모델 전환 후에도 채널 기록을 유지합니다.

## 문맥과 파일
- `/agent context action:status|reset|compact|configure`를 추가했습니다. `configure limit:2867`처럼 채널별 자동 압축 기준을 설정합니다 (1024~3584).
- 초기화는 대화와 요약만 지우고 프로젝트 정보·경로·설정·실제 파일은 유지합니다. 이전 작업이 기록을 복원하지 못하게 차단합니다.
- 자동 압축은 목표·검증 결과·현재 단계·남은 작업을 보존합니다. 압축 실패 시 원본을 유지하고, 압축 뒤에도 너무 크면 명확하게 안내합니다.
- 실제 실행 창 8192와 모델이 보고한 최대 문맥을 구분하고 턴 임베드에 문맥 추정·Ollama 입력/출력·보조 호출 수신 토큰을 표시합니다.
- 현재 프로젝트 채널의 텍스트/코드 첨부 목록·읽기·새 파일 저장·로컬 파일 업로드 도구를 추가했습니다. 읽기 1MiB, 업로드는 Discord 실제 한도와 10MiB 중 작은 값입니다. 이미지/PDF 시각 해석은 지원하지 않습니다.

## 업데이트와 검증
- **관리 앱과 Ollama 실행기를 함께 이 버전으로 업데이트하세요.** 실시간 출력·중지는 새 실행기 프로토콜이 필요합니다.
- 서버 접속 중 실제 앱 교체를 보장하는 TCP 개선은 이번 버전에서 제외했습니다. 기존 관리자 경유 TCP의 업데이트 대기는 유지하며 다음 업데이트 대상으로 미룹니다.
- Mac 기능 테스트 51개 통과: 빌드 실패→수정→재실행→보고, 실행 중 로그, 문맥 압축/초기화, Gradle 동의, Discord 표시·첨부 모의, 로컬 HTTP 스트림 취소 및 실행기 프로토콜 회귀. 저장 호환성 보강 뒤 관련 27개 추가 재검증 통과.
- 전체 테스트·다른 OS 검증은 사용자 요청으로 생략했습니다. 이번 변경의 실제 Discord 전송·실제 Qwen 품질과 TCP 접속 중 앱 교체는 미실행입니다. 기존 버전의 실모델 검증과 구분합니다.
- 새 설정은 별도 비공개 메타데이터에 저장하여 이전 베타의 대화 파일 파서를 유지합니다. 설치판·서명 검증 결과는 게시 후 개발 기록에 추가합니다.

## 로그 조회
- 콘솔과 로그 파일 보기가 파일 전체를 줄 번호로 조회합니다(`/instances/{id}/log-window`). 스크롤하면 필요한 구간을 이어서 불러오고, 검색은 서버에서 파일 전체를 대상으로 수행합니다. 압축 로그(.gz)는 펼친 크기 128 MiB까지 조회합니다.
- 콘솔을 가득 채우는 `[MunitionRackDebug]` 모드 로그는 저장·표시하지 않고, 이전 로그 파일을 읽을 때도 건너뜁니다. 줄 번호는 이 줄을 제외하고 센 번호입니다.
