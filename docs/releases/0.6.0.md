# Server Manager 0.6.0

## 다른 실행기를 직접 TCP 중계기로 사용

- 설치 화면에서 해당 컴퓨터 사용자가 중계를 허용한 뒤, 관리 웹 소유자가 중계 실행기를 준비·선택·전환합니다. 설정 파일을 직접 수정할 필요가 없습니다.
- 게임 트래픽은 플레이어 → 중계 실행기 → 게임 실행기 → Minecraft로 전달합니다. 관리 Mac은 인증·권한·경로 설정을 담당합니다.
- 새 대상의 준비 상태를 확인하고 전환하며, 즉시 차단 시 연결 손실 영향을 표시합니다. 로컬 허용 철회는 관리 웹에서 우회할 수 없습니다.
- 공유기 포트포워딩 입력값과 연결 진단을 제공합니다. 공유기·방화벽·DNS를 자동 변경하지 않습니다. 관리 서버 위치에서의 연결 검사는 외부 인터넷 전체에서의 도달 보증이 아닙니다.

## 게임 유지 업데이트와 로그

- 별도 상주 서비스가 게임 프로세스·콘솔·직접 중계 연결을 소유합니다. 호환되는 관리 앱·실행기 제어 계층 업데이트는 게임을 유지하면서 다시 연결할 수 있습니다.
- 기존 방식으로 실행 중인 게임의 최초 전환은 다음 정상 종료 뒤에 진행합니다. 상주 서비스 자체의 교체, 호환성 확인 실패, 파일 인계 등은 안전한 상태를 기다립니다. 모든 업데이트가 무중단인 것은 아닙니다.
- 앱 업데이트 버튼에서 실제 단계·대기 사유·진행 로그를 확인합니다. 실행기도 구성요소별 업데이트 내역을 표시합니다.
- 소유자 전용 관리 앱 로그 조회·필터·일시정지·내보내기를 추가했습니다. 조회 범위는 현재 앱 실행 중 수집한 제한된 로그이며 재시작 전 기록을 포함하지 않습니다.

## 설정 메뉴와 AI 비서

- 내 계정, 사용자·권한, 실행기·네트워크, AI 비서·에이전트, 연동 서비스, 시스템으로 설정을 나눴습니다.
- 기존 Gemini API 키 풀을 메인 에이전트에도 선택할 수 있습니다. 제공자별 요청·응답·도구 호출 처리를 지원합니다.
- 기존 Qwen 14B·30B 일반 대화와 실행기 선택 기능을 유지합니다. 파일 비서는 허용 폴더의 기존 텍스트 파일 1~5개, 파일당 48KB 안에서 작은 변경을 준비합니다.
- 모델 전송 동의 → 메인 모델 계획 → Qwen 초안 → 메인 모델 검토 → 소유자 최종 승인으로 진행합니다. 경로·링크·파일 변경 충돌을 검사하고 일회용 승인을 사용합니다. Discord에서도 소유자 계정 연결 후 비공개 승인 요청을 제공합니다.
- 파일 도구는 현재 macOS 관리 앱에서만 지원합니다. Aider는 설치·실행하지 않으며 기본 구조화 편집 엔진을 사용합니다. 명령 실행은 기본 금지입니다. 명시적으로 허용한 프로그램 실행은 OS 샌드박스가 아니므로 정확한 실행 파일·인자·작업 폴더와 위험을 승인 화면에 표시합니다.
- 사용자별 Google 연결로 Gmail·캘린더를 읽을 수 있습니다. 발송·삭제·일정 수정은 제공하지 않습니다. 별도 동의 후 제한된 조회 결과를 Qwen으로 요약하며 이 요약에는 메인 클라우드 검토를 사용하지 않습니다.

## 적용과 검증 범위

- 사용 방법: [직접 중계와 Qwen 비서 설정](https://github.com/yoonseo6399/ServerManager/blob/v0.6.0/docs/assistant-and-relay-setup.md).
- 실제 여러 컴퓨터·공유기·외부 인터넷 중계, 실제 Qwen 추론 품질·성능, 개인 Google OAuth·Discord 상호작용은 미검증입니다.
- 이번 실행 검증은 Mac에 한정합니다. 다른 운영체제의 실행 결과를 보장하지 않습니다.
- 릴리즈 게시 과정에서 운영 Minecraft나 관리 앱을 교체하지 않습니다. 설치·업데이트 적용 시 각 구성요소의 대기 사유를 확인하세요.
