# 0.7.0-beta.1 — Qwen 프로젝트 에이전트 시험판

- `/agent`로 Qwen 명령 통합: 개인 기본 모델·Thinking·승인 설정, 프로젝트 등록과 비공개 채널, 채널별 대화 문맥을 지원합니다. 기존 클라우드 명령은 `/cloud-agent`입니다.
- 파일·검색·명령·빌드·테스트·Git·프로젝트 생성 도구를 추가했습니다. 실행 전 독립된 Qwen 대화가 위험성을 검토하고 Discord 버튼으로 승인합니다.
- 명시적 승인이 기본이며 자동 모드에서도 프로젝트 밖 경로와 범위를 판정할 수 없는 명령은 사용자 승인 대상입니다. OS 샌드박스는 아니며 관리 앱 OS 사용자 권한으로 실행합니다.
- 메인 답변·Thinking은 채널 메시지로, 무거운 도구의 전체 입력·결과는 턴별 스레드로 표시합니다. 모델에는 긴 로그를 줄여 전달합니다.
- 요청자의 Discord 표시 이름과 ID를 메인·분류·감시 Qwen에 전달하며 권한은 ID로 확인합니다.
- 실행기 Ollama 대화 프로토콜을 확장했습니다. 다른 컴퓨터에서 추론하려면 해당 실행기도 이 버전으로 업데이트해야 합니다. 파일·셸 도구 실행 위치는 관리 앱 컴퓨터입니다.

관련 기능 자동 테스트 32개, 프런트엔드·JAR 빌드, 실제 Qwen 14B 임시 파일 수정·승인과 Thinking 스트림 검증을 통과했습니다. 전체 테스트는 사용자 요청으로 생략했습니다. 실제 Discord 상호작용·30B 품질 및 다른 OS 검증은 미실행입니다. 패키징·서명 결과는 릴리즈 작업의 성공 여부를 확인하세요.

안정판 자동 업데이트에는 노출되지 않는 베타입니다. 첫 테스트는 베타 macOS PKG를 설치하세요. 사용법과 제한: [Qwen 프로젝트 에이전트](https://github.com/yoonseo6399/ServerManager/blob/v0.7.0-beta.1/docs/qwen-project-agent.md).
