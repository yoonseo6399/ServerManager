# 0.7.0-beta.3 — Qwen, 실행기 릴리즈 선택과 안정판 롤백

Qwen 프로젝트 하네스와 관리 앱·실행기 릴리즈 선택, 베타 동의, 진행률·상태·로그, 명시적 안정판 롤백을 함께 제공합니다. `/agent`는 Qwen, 기존 클라우드 작업은 `/cloud-agent`입니다. 요청자의 Discord 표시 이름과 ID를 전달하며 실제 권한은 ID로 검사합니다.

실행기 카드에서 **릴리즈 목록 새로고침 → 버전 선택 → 설치**를 사용합니다. 안정판 실행기도 베타 동의가 있는 수동 요청은 선택한 베타를 받습니다. 구형 실행기는 먼저 **원격 업데이트 요청**으로 최신 안정판 제어 계층을 받고 재연결해야 합니다. 적용은 실제 대기 매니페스트의 버전을 기준으로 확인하며, 다른 요청의 실패 상태가 대기 대상에 영향을 주지 않도록 보완했습니다.

**관리 앱 PKG와 실행기 ZIP 설치판을 한 번 적용해야 롤백 부트스트랩이 설치됩니다.** 일반 JAR 자동 업데이트는 부트스트랩을 바꾸지 않습니다. beta.1/beta.2 사용자는 이번 beta.3 설치판으로 올리세요. 이후 릴리즈 목록에서 안정판 **0.6.3**을 선택하고 별도 롤백 동의 후 돌아올 수 있습니다. 낮은 안정판은 0.6.0 이상만 지원하며, 프로필·월드를 과거 시점으로 복원하지 않습니다. 서명·해시·호환성·안전 적용·시작 실패 복구를 유지합니다.

통합 소스의 관련 백엔드 66개·브라우저 4개, 프런트/bootJar, 실제 임시 관리 앱·실행기 부트스트랩의 승인 롤백/유지/변조 거부/무승인 차단/실패 복구와 격리 웹의 공개 안정판 다운로드·서명·계정 보존을 확인했습니다. 전체 테스트·다른 OS·실제 Minecraft 운영 검증은 요청대로 생략했습니다. 실제 14B 추론은 beta.1 개발 단계에서 확인한 결과이며 이번에는 품질/속도를 다시 측정하지 않았습니다.

beta.2 릴리즈는 게시 취소 상태를 잘못 확인한 삭제 절차 실수로 삭제됐습니다. 해당 태그는 유지하며 같은 버전의 파일을 재생성하지 않고 beta.3으로 대체합니다. 안정판 파일은 변경하지 않았습니다.
