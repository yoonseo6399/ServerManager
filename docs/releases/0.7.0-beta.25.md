# Server Manager 0.7.0-beta.25

코드 리뷰에서 발견한 데이터 보존·권한 처리 문제와 UI 사용 흐름을 개선했습니다. 관리 앱과 실행기를 함께 업데이트하세요.

- **파일 편집 보호:** 서버·폴더 전환의 오래된 응답을 폐기하고 파일 작업 대상을 고정합니다. 닫기·탭·서버·뒤로가기에서 미저장 변경을 확인하며, 저장 중 이동을 막고 충돌/실패 때 초안을 유지합니다.
- **오류 복구:** 목록의 로딩·빈 상태·실패를 구분하고 다시 시도를 제공합니다. 서버 상태 갱신 실패와 마지막 확인 시각을 표시하며 보조 메모리 조회 실패가 서버 목록을 막지 않습니다. 서버 삭제는 필요시 패스키를 다시 확인하고 원래 대상에 한 번 재시도합니다.
- **키보드·모바일:** 서버 생성과 팩 가져오기에 공통 모달, 포커스 순환/복귀, Escape·뒤로가기 처리를 적용했습니다. 모바일 관리 메뉴 접기, 파일 작업 터치 영역과 긴 이름 표시를 개선했습니다. 서버 생성 입력 범위 검증과 설정 초안 보존도 보완했습니다.
- **권한 설정 보호:** 손상되거나 읽을 수 없는 Discord 권한 파일은 기본 허용으로 대체하지 않고 실행을 차단합니다. 원본을 보존하며 정상 백업 복원 후 재시작을 안내합니다.
- **텍스트 보존:** 로컬·원격 파일의 UTF-8 오류를 엄격히 검사합니다. 기존 EUC-KR/CP949 같은 파일은 자동 변환·저장하지 않고 원본 다운로드를 안내합니다.
- **저장 공간:** 만료된 팩 미리보기는 24시간 후 정리하며 활성 작업과 링크는 보호합니다. 미리보기 보관은 최대 8개입니다. 종료 스냅샷이 일반 복사로 전환될 때 전체 파일 크기를 기준으로 공간을 다시 검사합니다.

사전 검증: 백엔드 범위 테스트 **42개**, 모의 API 브라우저 **27개**, TypeScript/Vite 빌드 통과. 데스크톱·390px 모바일 화면 확인. 릴리즈 CI는 전체 백엔드 테스트와 패키징·서명·격리 부트스트랩 검증을 실행합니다. 실제 장치 WebAuthn·화면낭독기·Windows 저디스크·운영 Discord/게임 검증은 포함하지 않습니다.
