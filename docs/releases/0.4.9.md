# Server Manager 0.4.9

- 대용량 서버 파일 인계 후 확인 요청이 시간 초과되어 재시도·서버 시작 대기가 반복되는 문제를 수정했습니다. 중앙의 파일 해시 검증을 제한된 백그라운드 작업으로 처리하고, 확인 요청은 진행 중인 검증을 재사용합니다.
- 검증 결과는 메모리에만 보관하며 파일 변경·추가·삭제, 경로·실행 상태 변경 시 다시 검증합니다. 파일 내용의 전체 해시 검증과 중단된 전송 보호는 유지합니다.
- 실행기는 중앙 검증이 진행 중일 때 기다린 후 다운로드를 이어갑니다. 기존 실행기의 인계 복구 요청도 HTTP 503 재시도로 호환됩니다.
- 플레이어가 없어 절전 종료한 서버가 연결 복구 후 비정상 종료로 표시될 수 있는 문제를 수정했습니다. 실행기의 종료 사유를 중앙에 보존하고 Discord에 **무인 절전 종료**로 표시합니다.
- Discord에서 서버를 시작·재시작한 사람의 이름과 프로필 이미지를 시작 완료 임베드에 표시합니다. 웹 시작과 자동 재시작도 실행 경로를 구분합니다.
- 계정·패스키·기존 서버 폴더·월드·모드는 유지됩니다. 이미 게시된 버전의 설치 파일은 교체하지 않습니다.
