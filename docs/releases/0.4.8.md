# Server Manager 0.4.8

- 모드 페이지를 필터 사이드바·카드 목록·상단 고정 작업 바로 개편했습니다. 개별 스위치와 선택 활성화/비활성화를 지원합니다.
- JAR 내부 의존성 검사를 제거했습니다. 파일 SHA-512로 Modrinth의 정확한 버전과 의존성을 조회해 서버별로 저장하고 재사용합니다. 필요한 프로젝트·정확한 버전·내장·비호환 조건을 보존합니다.
- 다른 활성 모드가 필수로 사용하는 제공 모드는 끌 수 없으며 사용 중인 모드 이름을 표시합니다. 소비 모드는 개별 비활성화할 수 있습니다. 활성화할 때 필요한 비활성 의존성을 함께 복구합니다.
- 미확인 파일의 의존성을 없다고 추측하지 않습니다. 안전성을 확인할 수 없는 변경과 진단은 사유를 표시해 보류합니다. 정확한 Modrinth 버전 링크로 같은 해시·크기의 파일을 연결할 수 있습니다. 사설·수정 파일을 다른 공개 파일로 임의 연결하지 않습니다.
- mrpack은 남길 모드의 전이 의존성을 먼저 보호한 뒤 클라이언트 전용 파일을 제외합니다. 미확인 소비 모드가 있으면 JAR 자동 제외를 보류하고, 필수 버전이 없으면 가져오기를 중단합니다.
- 서버 설정·도메인·절전·자동 재시작·Discord·WebDAV·프로필 위치에 화면 하단 변경 사항 바를 추가했습니다. 저장/되돌리기, 저장 실패 시 입력 보존, 미저장 이동 확인을 지원합니다.
- 정상 종료 신호 뒤 저장 진전이 3분 연속 없으면 해당 Minecraft 프로세스만 자동 강제 종료합니다. 서로 다른 저장 단계 로그와 실제 월드 저장 파일 쓰기는 타이머를 갱신합니다. 반복 오류 로그는 갱신하지 않습니다. 종료된 프로세스의 파일 인계는 강제 종료하지 않습니다. 저장되지 않은 변경은 손실될 수 있으며 종료 사유를 웹과 Discord에 표시합니다. 원격 서버는 실행기 0.4.8 이상이 필요합니다.

서버 관리 앱의 Sable 호환성 검사는 보조 모드 ABI 확인을 위한 ID·버전만 읽습니다. 모드 의존성 검사에는 JAR 내부 정보를 사용하지 않습니다. 관리 앱이 제공하는 보조 모드는 정확한 포함 파일 해시로 식별합니다.
