# Server Manager 0.5.1

- 웹 설정(계정과 보안)에 "Qwen (Ollama)" 항목을 추가했습니다. `/local-llm`을 처리할 서버 실행기를 지정하고, 기본 모델을 Qwen3 14B와 30B 중에서 동적으로 바꿀 수 있습니다.
- 지정한 실행기의 Ollama 환경(버전, 14B·30B 설치 여부, 메모리에 올라간 모델)을 원격으로 확인하고 모델을 메모리에서 내릴 수 있습니다. 실행기 컴퓨터에서 `llm-enabled`로 허용한 경우에만 사용할 수 있습니다.
- Qwen 모델은 동시에 하나만 메모리에 올립니다. 요청 전에 다른 Qwen 모델을 먼저 내리고 내려간 것을 확인하며, 확인되지 않으면 요청을 중단합니다. 다른 종류의 모델은 건드리지 않습니다.
- Discord `/local-llm`의 `model` 옵션은 생략하면 웹 설정의 모델을 씁니다. 실행기를 지정한 경우 그 실행기를 쓸 수 없으면 관리 앱 컴퓨터로 대체하지 않고 이유와 함께 실패합니다.
- 0.5.0의 Qwen 실행기 실행, 음악 한 곡 반복·패널 토글, 0.4.14 기능을 유지합니다.

사용 방법: `docs/luonnotar-agent.md`.
실제 Ollama·실행기 연결 Qwen 추론은 이 환경에서 검증하지 않았습니다.
