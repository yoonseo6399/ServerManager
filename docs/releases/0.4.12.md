# Server Manager 0.4.12

- 모드 화면에서 Modrinth에 등록되지 않은 모드가 일부 있어도 나머지 모드의 활성·비활성 전환과 문제 모드 찾기 검사를 계속 사용할 수 있습니다. 이전에는 미확인 모드가 하나만 있어도 모든 모드에 "다른 활성 모드의 의존성을 확인할 수 없습니다" 차단이 표시되었습니다.
- 미확인 모드는 경고로만 표시됩니다. 변경 확인 창에 영향을 받을 수 있다는 안내가 나타나고, 미확인 모드 자체도 켜고 끌 수 있습니다.
- Modrinth가 확인한 필수 의존성 보호는 그대로 유지됩니다. 다른 모드가 필요로 하는 라이브러리는 여전히 비활성화할 수 없습니다.
- 계정·패스키·기존 서버 폴더·월드·모드는 유지됩니다. 이미 게시된 버전의 설치 파일은 교체하지 않습니다.
