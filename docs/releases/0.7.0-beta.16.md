# 0.7.0-beta.16 — Qwen3.8 모델과 추론 상태

- Discord `/agent`와 관리웹 모델 목록에 **Qwen3.8 27B (Ollama Q4_K_M)**, **Qwen3.8 Flash-Next (Strata Q2_0 SSD 오프로딩)**를 추가했습니다. 관리 앱과 실제 추론 실행기를 모두 업데이트하세요. 기존 기본 모델은 유지됩니다.
- Flash-Next는 Apple Silicon Mac에서 관리웹 **AI 비서·에이전트 → 로컬 LLM → 실행 환경 확인 → Flash-Next 설치**로 준비합니다. 모델 약 66.4GB, 여유 공간 75GB 필요. 검증한 8K 실행 창을 지원하며 첫 요청에서 자동 시작합니다. 16K로 설정한 채널은 8192로 바꿔주세요.
- 설치 진행 상태·로그와 추론 컴퓨터의 RAM·스왑·메모리 압력·모델 메모리·현재 GPU wired 한도를 표시합니다. 환경 조회 후 10초마다 갱신됩니다. 자동 선택의 환경 조회는 관리 앱 컴퓨터이며 실행기를 직접 고르면 해당 원격 컴퓨터의 값입니다.
- Discord 턴 임베드에 실제 생성 속도(tok/s)와 완료 시점 메모리를 추가했습니다. 로딩·입력 처리 시간을 제외한 엔진 메트릭을 쓰며 미수신 값은 추정하지 않습니다. Strata RSS 합계는 공유 페이지가 중복될 수 있습니다.
- Strata의 공식 도구 호출·실시간 출력·문맥을 기존 승인 하네스에 연결했습니다. 모델 전환 시 이전 관리 모델을 내리고, 소유한 Strata 프로세스만 중지합니다. 오래 걸리는 Flash-Next 입력 처리는 최대 20분, 에이전트 중지 지원. macOS15.1 호환 옵션을 적용했습니다.

검증: 관련 백엔드 38개, Playwright 모델 선택·저장·메모리·설치 버튼 1개, frontend/bootJar, runner setup·bootstrap 통과. 이 Mac(M4 Pro/24GiB/macOS15.1)에서 두 모델의 실제 파일 read_file→결과 반영·CRLF 원문 보존과 메트릭 수신, Flash-Next 실행 중 취소 및 프로세스 정리를 확인했습니다. 작은 두 턴 호출에서 27B 약 12.73tok/s, Flash-Next 7.9tok/s였습니다. 모델 전체 성능 비교 수치는 아닙니다.

전체 테스트와 다른 OS 실행은 사용자 요청으로 생략했습니다. 실제 Discord 상호작용, 새 컴퓨터에서 66.4GB 첫 다운로드, 긴 8K/16K 문맥은 미실행입니다. 기존 4가지 파일 편집/별 Python 측정은 별도 API 실험 결과이며 이번 변경의 전체 하네스 검증으로 주장하지 않습니다. 세부 사용법·측정 구분은 `docs/qwen38-models.md`를 참고하세요.

앱은 OS 메모리 한도를 변경하지 않습니다. 테스트 Mac의 20GiB 설정은 사용자 요청에 따라 유지했으며 재부팅 지속 설정은 설치하지 않았습니다. Stable/latest는 기존 버전을 유지합니다.
