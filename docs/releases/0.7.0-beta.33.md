# Server Manager 0.7.0-beta.33

관리웹과 서버 실행기를 모두 업데이트하세요. 기존 안정판은 변경하지 않습니다.

## beta.32 이후 보완
- Minecraft가 매우 빨리 종료되어 Process.info 조회가 실패하거나 달라져도, 시작 시 만든 로그 세션 식별값을 같은 프로세스에서 계속 사용합니다. 현재 시작 실패 로그가 이전 세션 기록으로 대체되거나 누락되는 경합을 막습니다.
- beta.32의 공개 파일·태그는 변경하지 않았습니다. 아래 로그·Mixin·런타임 변경 기능을 모두 포함한 후속 릴리즈입니다.

## 로그
- 실시간 콘솔은 현재 Minecraft 실행 세션의 `live.log`만 표시합니다. 이전 세션을 포함한 누적 `console.log`는 파일 목록에서 별도로 열 수 있습니다. 제어 계층 재연결·앱 업데이트로 같은 게임에 재접속할 때는 세션을 초기화하지 않습니다.
- 원문 보기와 블록 보기에서 열린 로그 파일 전체를 백그라운드 검색합니다. 스크롤하지 않아도 검색이 진행되며 진행률·전체 일치 수·결과 페이지를 표시합니다. 검색어/파일/필터 변경이나 화면 종료 시 이전 작업을 취소합니다.
- 제외 키워드·모드/로거·DEBUG 조건을 검색에도 적용합니다. 숨긴 헤더에 속한 스택 연속 행도 검색 결과에서 제외합니다. 조회 사용자는 자신의 검색만 조회·취소할 수 있습니다.
- 검색은 시작 시점의 파일 전체를 대상으로 하며 새 로그를 포함하려면 ‘다시 검색’을 누릅니다. 메모리 보호를 위해 일치 수는 전체 계산하되 결과 위치는 최초 100,000개까지 표시합니다. 긴 행의 결과 미리보기는 앞 16 KiB까지 표시합니다.
- 구형 실행기는 현재 세션 로그·전체 검색을 지원하지 않으므로 실행기도 업데이트해야 합니다. 기존 파일 기록은 삭제하지 않습니다.

## Mixin 분석창
- 큰 분석 결과에서도 닫기가 화면 상단에 유지됩니다. Escape·배경·뒤로가기로 닫을 수 있고 요청·파싱 중 닫은 창이 늦은 응답으로 다시 열리지 않습니다.
- 원문·프레임·Mixin은 페이지로 나눠 표시하며 모바일에서도 본문을 스크롤할 수 있습니다.

## 서버 모드로더·Minecraft 버전 변경
- 각 서버의 ‘서버 설정 → 모드로더·Minecraft 버전 변경’에서 공식 대상 버전을 선택하고 중앙 확인 창에서 변경 내용을 검토할 수 있습니다.
- 같은 모드로더 종류 안에서 로더 버전을 변경하거나 Minecraft 버전을 올릴 수 있습니다. Minecraft 다운그레이드는 지원하지 않습니다.
- 서버와 파일 전송이 끝난 뒤 선택된 실행기 원본 폴더에서 처리합니다. 공식 런타임을 별도 폴더에 설치·검증한 뒤 실행 파일과 라이브러리만 반영하며 기존 실행 파일 백업·진행 로그·실패 상태를 표시합니다. 중간 반영 실패는 기존 실행 파일로 복구합니다.
- 월드·mods·config·KubeJS와 기존 JVM 인자는 보존합니다. 모드는 자동 업데이트되지 않으며 새 Minecraft/로더 호환성은 사용자가 확인해야 합니다. 변경 전 월드 백업을 준비하세요. 새 Minecraft로 월드를 연 뒤의 되돌리기는 런타임 백업만으로 보장하지 않습니다.
- 원자로 폭발 방지 보조 모드와 Survival 월드 복구는 개별 서버 운영 변경으로, 이 일반 ServerManager 설치판에 자동 포함하지 않습니다.

## 검증과 범위
- 120만 줄 파일 끝부분 검색, 제외 필터·스택·gzip, 세션 초기화/재연결, 검색 소유권 및 실행기 읽기 전용/실행 중 변경 차단을 검증했습니다.
- 런타임 파일 한정 반영, 월드·모드·설정 보존, 중간 반영 실패 복구, 사용자 지정 JAR, 다운그레이드/동일 버전 거부를 검증했습니다.
- 격리 실행기 작업 경로에서 공식 Mojang JAR 다운로드·해시 검증을 거쳐 Minecraft 1.21.1 → 1.21.2 실행 파일 교체와 원본 월드 바이트 보존을 확인했습니다. Minecraft 프로세스는 실행하지 않았습니다.
- 관련 브라우저 19개와 TypeScript/Vite 빌드 통과. 실제 NeoForge/Forge/Fabric/Paper 버전 변경·월드 로드/모드 호환성·다른 OS 실행은 미실행입니다. 기존 요청에 따라 전체 백엔드 회귀는 생략하고 관련 기능 검증과 패키징 검사를 수행합니다.
