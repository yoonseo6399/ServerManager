# 0.7.0-beta.2 — Qwen 시험판과 실행기 선택·안정판 롤백 통합

0.7.0-beta.1의 Qwen 프로젝트 에이전트에 0.6.1/0.6.2의 관리 앱·실행기 릴리즈 선택 화면, 진행 상태·로그, 명시적 안정판 롤백을 통합했습니다. 실행기에서 `OLLAMA_AGENT_V2`와 업데이트 선택/롤백 기능을 함께 보고하도록 병합했습니다.

- `/agent`: 개인 기본 모델, 기본 Thinking, 비공개 프로젝트 채널과 대화 문맥, 파일·검색·명령·빌드·테스트·Git·프로젝트 도구, 독립 감시 Qwen과 승인 버튼을 제공합니다. 요청자의 표시 이름과 ID를 전달하고 권한은 ID로 확인합니다. 기존 클라우드 명령은 `/cloud-agent`입니다.
- 실행기별 릴리즈 목록·베타 동의·대상 버전·다운로드 진행률·검증·적용 대기/실패 로그를 표시합니다. 안정판 실행기에서도 명시적 베타 선택이 가능합니다. 구형 실행기는 먼저 최신 안정판 제어 계층으로 업데이트해야 합니다.
- 관리 앱과 실행기에서 별도 동의로 0.6.0 이상 낮은 안정판에 돌아갈 수 있습니다. 낮은 베타는 거부하고, 서명·해시·호환성 검증·안전 적용·시작 실패 복구를 유지합니다. 월드/설정의 시점 복구는 아닙니다.

**롤백을 사용하려면 이번 PKG와 실행기 ZIP 설치판을 한 번 적용하세요.** JAR 자동 업데이트는 부트스트랩을 교체하지 않습니다. 이미 beta.1이라면 이번 beta.2 설치판으로 올려야 새 화면과 부트스트랩을 함께 사용할 수 있습니다. 이후 릴리즈 목록에서 안정판 0.6.2를 선택하고 롤백에 동의할 수 있습니다. 모델 추론은 선택 실행기에서 하더라도 파일·셸 도구는 관리 앱 컴퓨터의 OS 사용자로 실행되며 OS 샌드박스는 아닙니다.

베타 통합본의 관련 백엔드 65개·브라우저 4개와 프런트/bootJar 빌드가 통과했습니다. 전체 테스트·다른 OS·실제 Minecraft 운영 검증은 사용자 요청으로 생략합니다. 기존 14B 임시 파일 수정/승인·Thinking 검증은 beta.1 개발 단계에서 수행한 결과이며 이번 통합에서 모델 품질을 다시 측정하지 않았습니다. 통합 기능 검증과 서명·패키징 결과는 개발 기록과 릴리즈 CI를 참조하세요.
