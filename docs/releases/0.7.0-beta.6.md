# Server Manager 0.7.0-beta.6

최신 beta.5 기반 Qwen 도구 누락·대화 대상 판별 수정입니다.

- 모델이 “읽어볼게요/찾아볼게요”라고 답한 뒤 실제 도구 없이 종료하면 최대 2회 보정 요청합니다. 계속 도구가 없으면 미실행으로 중단을 보고하고 완료로 처리하지 않습니다. 백엔드가 임의 명령을 만들거나 승인을 우회하지 않습니다.
- `read_file`, 첨부 읽기, 목록·검색은 기본적으로 원문을 전달합니다. 모델이 `summarize:true`를 명시한 경우에만 기존 요약 경로를 사용합니다. 예산 초과 시 원문 범위와 이어 읽을 위치를 표시하며 의미를 재작성하지 않습니다. 자동 문맥 압축은 별도 정책으로 유지됩니다.
- Discord 대화 대상 판별에서 코딩용 Qwen 호출을 제거했습니다. 참여자가 한 명인 채널, 봇 멘션·별칭·답장은 즉시 판별하고 애매한 여러 사람 대화는 명시적 호출을 안내합니다.
- 최근 15분/채널별 최대64개 발언의 참여자·답장 관계를 별도 비공개 파일에 저장합니다. 시작 후 첫 소유자 요청에는 최근25개 메시지를 복원합니다 (조회 최대5초). 봇·상태 임베드는 사람 수에 포함하지 않습니다.
- 인식 완료 상태와 `/agent context action:status`에 관측된 참여자 수를 표시합니다. 다른 사람의 참여가 실행·승인 권한을 주지는 않습니다.

관리 앱과 실제 Qwen 추론을 담당하는 실행기를 모두 이 버전으로 업데이트하세요. 실행기의 위험검토 JSON Schema 적용까지 필요합니다. 실제 Discord 속도·인터랙션은 미검증이며, 자연어 검사와 규칙 기반 대상 판별이 모든 오류를 검출한다고 보장하지 않습니다.

- 실제 Qwen에서 발견된 최상위 `tool_name/arguments` 형식은 명시된 도구 구조만 정규화해 기존 승인 경로로 전달합니다. 모순되거나 누락된 구조는 재요청합니다.
- 위험 검토용 독립 모델에 JSON Schema와 temperature 0을 적용합니다. 판정 실패 시 차단 정책은 유지합니다.
- 사용자가 저장 후 재조회를 요청한 경우, 해당 파일의 `read_file` 검증이 끝나기 전에 완료로 종료하지 못하도록 추적합니다. 대화 기록만으로 답하라는 요청에는 파일 도구를 실행하지 않습니다.

Mac에서 관련 회귀61개와 실제 Qwen3 30B 시험2개가 통과했습니다. 실제 파일 읽기/원문 전달/대화 후속 시험73.3초, 파일 편집 연쇄 시험84.8초. 연쇄 시험은 `read_file → write_file → read_file`과 저장 승인1회를 거쳤으며 최종 파일 전체 바이트가 `existing-line\nvalue=42\nCHAIN_VERIFIED_7D31\n`와 정확히 같음을 검증했습니다. 원문 두 줄을 보존하고 요청한 파일 끝에 문구를 추가했습니다. 운영 파일과 Discord에는 쓰지 않았습니다.

실제14B·Discord·다른 OS 검증은 미실행이고 전체 테스트는 사용자 요청으로 생략했습니다. 배포 파일의 서명·해시 검증 결과는 게시 후 개발 기록에 남깁니다.
