# Server Manager 0.7.0-beta.9

beta.8을 기반으로 한 테스트용 베타입니다.

## Discord Qwen 에이전트
- **실시간 개입**: 작업 중 같은 채널에 보낸 소유자의 메시지가 진행 중인 작업의 다음 단계에 반영됩니다(🧭 표시). 방향을 바꾸는 지시는 이전 목표를 갱신하고, 승인 권한은 주지 않습니다.
- **edit_file 재조회 검증**: "저장 후 다시 읽어서 검증" 요청에서 `edit_file` 수정도 `write_file`처럼 재조회 전에는 완료로 인정하지 않습니다.
- **긴 명령 출력 보관**: 긴 `run_command`·`build`·`test` 출력을 요약하지 않고 보관하며 `read_result`로 구간을 읽습니다.

- **요구사항 장부와 완료 게이트**: 40자 이상 요청을 항목으로 나눠 고정하고, 모델이 끝내려 해도 열린 항목이 있으면 최대 3번 다시 요청합니다. 행동 항목은 변경 도구가 성공해야 닫히며, 최종 보고에 항목별 상태가 붙습니다.
- **작업 노트**: 직전 요청·결과·바뀐 파일·미완료 항목을 채널별로 보관해 "계속해줘" 같은 후속 요청에서 문맥을 잃지 않게 합니다. `/agent context reset`으로 지워집니다.
- **`rg` 명령과 `search` 도구**: 외부 프로그램 없이 서버 안에서 동작하는 ripgrep 호환 검색입니다. 지원하지 않는 옵션은 거부합니다.
- **입력 예산**: `PROJECT_AGENT_INPUT_BUDGET`(3600~12000)로 큰 창의 실행기에서만 올릴 수 있습니다. 기본값은 그대로입니다.

## 월드 전송
- 실행기 폴더 가져오기에서 이전에 검사한 파일을 다시 읽지 않고, 진행 단계(목록 작성·비교)를 더 일찍 표시합니다.
