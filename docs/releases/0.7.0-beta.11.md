# 0.7.0-beta.11 — 로컬 에이전트 도구 호출·문맥 안정화

Beta 10 구조를 유지하면서 로컬 에이전트가 도구 실행 예고만 하고 끝내거나, 이미 수정한 내용을 잊고 반복 조회하는 문제를 보완했습니다. **관리 앱과 LLM을 실행하는 실행기를 모두 Beta 11로 업데이트**해야 공식 도구 호출과 새 문맥 프로필을 사용할 수 있습니다. 구형 실행기에 조용히 낮은 기능을 적용하지 않고 업데이트 안내를 표시합니다.

## 변경 사항

- Ollama 공식 `tools` / `message.tool_calls` / `role:tool`을 Discord 에이전트의 기본 경로로 채택했습니다. 역할별 기본 도구, 추가 도구 선택, 근거를 포함한 `report_task`를 지원합니다. 기존 권한·독립 위험 검토·사람 승인을 유지하며 텍스트 안의 도구 JSON은 실행하지 않습니다.
- 원문 목표·작업 계획·요구사항·실제 변경 지문·저장한 교체 내용과 남은 재조회를 요약과 별도로 유지합니다. 미호출 교정, 동일 입력·동일 결과 반복 제한, 파일별 완료 근거 검사를 추가했습니다. 중단 시에도 이미 저장된 변경 파일과 전체 완료 여부를 구분합니다.
- 읽기 결과는 별도 요약을 요청하지 않으면 원문을 전달합니다. 검색 옵션·파일 이름 검색을 보완하고, 기존 파일의 사전 읽기와 `edit_file` 부분 변경을 검사합니다. CRLF·마지막 개행 보존, 원본을 보존한 병합 후 삭제를 검증했습니다.
- `/agent context action:configure window:16384`로 16K를 선택할 수 있습니다. 기본은 8K이며 `limit`, `output`으로 압축 기준과 출력 예약을 조정합니다. 상태·턴 표시에서 실행창·입력 예산·출력 예약·모델 최대치를 구분합니다. 설정·계획을 별도 비공개 파일에 보관하고 초기화·구형 롤백 경계를 유지합니다.
- Git 읽기 명령의 알려진 비밀 경로·raw blob 우회를 제한했습니다. 소유자 도구는 OS 사용자 권한으로 실행되며 OS 샌드박스라는 의미는 아닙니다.

## 실제 비교와 검증

동일 코드, Mac 24 GiB, Qwen3 14B, Thinking 켬, 8K에서 임시 파일의 한 문구만 바꾸는 과제를 비교했습니다. **공식·JSON 양쪽 모두 요청한 수정과 나머지 전체 원문·CRLF·개행 보존에 성공**했습니다.

| 방식 | 검증·최종 보고 | JUnit 시간 |
| --- | --- | ---: |
| 공식 도구 호출 | 검색 → 읽기 → 수정 → 재조회 후 완료 근거 보고 성공 | 187.1초 |
| 기존 JSON | 수정·재조회 성공, 완료 근거 누락과 반복 조회로 중단 | 254.3초 |

각 방식 한 과제 한 번의 결과이며 일반 성능 순위가 아닙니다. 이 과제의 완결성과 시간에 근거해 공식 방식을 기본으로 결정했습니다. 두 최종 8K 시험 모두 메모리 압력 정상, 관측 스왑 증가 0 MiB였고 모델을 해제했습니다. 비교 후에는 중단 보고의 실제 변경 표시만 추가 보완하여 별도 회귀를 수행했습니다.

- 기능 회귀: 168개 중 160개 통과·실제 모델 opt-in 8개 건너뜀·실패 0. 마지막 종료 표시 보완 뒤 관련 21개 회귀 모두 통과.
- 격리 부트스트랩: 서명 업데이트·변조 거부·시작 실패 롤백·프로필 선택 통과.
- 릴리즈 CI는 프런트 빌드·배포 JAR·Mac 설치 패키지와 Mac/Windows 실행기 압축 파일·업데이트 서명을 생성합니다. 다른 OS에서 실행 검증했다는 의미는 아닙니다.
- 전체 테스트는 사용자 요청으로 생략합니다. 운영 앱·실행기·게임호스트는 이 게시 작업으로 교체하지 않습니다.

## 남은 한계

모델의 잘못된 인자·반복·요약 오류 자체를 완전히 없애지는 못합니다. 백엔드가 일부 오류를 거부·중단하며 임의 요구사항의 의미를 완전히 증명하지는 않습니다. 실제 Discord 버튼/출력, 원격 설치 후 양단, 이번 하네스의 30B/Coder/Gemma 및 여러 과제·장시간 품질은 미검증입니다.

개발 중 14B 16K 시험은 실제 로드와 파일 수정을 확인했으나, 공식 방식에서 압력 경고·최대 약 360.6 MiB 스왑 증가와 보고 시간 초과가 있었습니다. 최종 보완 뒤 16K A/B와 **16K 전체 입력 길이**는 검증하지 않았습니다. 메모리가 제한된 환경은 기본 8K부터 사용하세요.
