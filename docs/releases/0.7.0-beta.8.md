# Server Manager 0.7.0-beta.8

beta.7을 기반으로 한 테스트용 베타입니다.

## 관리 웹
- 다른 창에 오래 머문 뒤 로그인하면 "권한이 없거나 요청 검증에 실패했습니다"가 뜨고 새로고침해야 하던 문제를 고쳤습니다. 만료된 보안 토큰을 자동으로 갱신해 한 번 다시 시도합니다.

## Discord Qwen 에이전트
- Discord 최고 관리자 역할이 계정 연결 없이 소유자로 인정됩니다(`/agent`).
- 최고 관리자는 `/agent access`로 친구 역할을 열고, 역할마다 쓸 수 있는 모델(14B/30B), 권한(읽기 전용/승인 후 부분 수정), 최대 턴 수, 공유 프로젝트를 정합니다.
- 친구는 프로젝트 폴더 안에서만 작업하며 비밀 파일을 읽지 못하고, 수정은 항상 본인 승인을 거칩니다.
- 요청당 최대 턴 수를 12에서 기본 30(상한 100)으로 늘렸고 `/agent turns`, `/agent run turns:`, 서버 상한으로 줄이거나 조절할 수 있습니다.
- Qwen 30B용 도구: `grep`, `&&`, 파이프를 쓰는 읽기 전용 `sh`와 줄/문구 단위 `edit_file`. 읽기 전용 도구는 모델 위험 검토와 결과 요약을 건너뛰어 호출이 줄고 원문이 유지됩니다.

## 검증
- 관련 단위 테스트를 Windows에서 일부 환경 완화로 실행했습니다. 실제 Qwen 30B와 Discord, macOS CI, 프런트엔드 빌드는 미검증입니다. 자세한 내용은 `docs/dev-notes/feat-qwen-friend-harness.md`.
