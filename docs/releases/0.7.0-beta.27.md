# Server Manager 0.7.0-beta.27

## 음악 자동재생

- 자동재생 중 다음 버튼으로 다른 추천곡을 불러옵니다. 대기열이 있으면 먼저 재생합니다.
- 건너뛴 곡의 선택 가중치를 서버별로 저장해 낮춥니다. 다른 후보가 없으면 같은 곡을 곧바로 반복하지 않고 안내합니다.

## 모드·파일 관리

- 모드 탭에서 JAR 파일 드래그 또는 선택 업로드를 지원합니다. 모드·파일 업로드 상태를 하단 floating progress bar에 표시합니다.
- 모드 카드의 휴지통 버튼으로 삭제할 수 있습니다. Shift를 누르고 클릭하면 삭제 확인을 생략합니다.
- 클라이언트 전용 모드 제외 체크박스는 기존 화면을 유지했습니다. 미확인 모드가 하나 있다고 확인된 클라이언트 모드까지 전부 유지하던 문제를 고쳤습니다. 팩 선언·Modrinth·Fabric 실행 환경 정보를 사용하며, 알려진 필수 의존성은 보호합니다.

## 기존 서버의 mrpack 업데이트

- 모드 탭의 **mrpack으로 서버 업데이트**에서 중앙 모달로 변경 내역을 검토합니다.
- 기존 모드에 추가·덮어쓰기 또는 팩 목록으로 교체를 선택합니다. 추가·덮어쓰기·삭제 모드 목록, config 덮어쓰기와 클라이언트 전용 모드 제외 옵션을 제공합니다.
- 월드·플레이어 데이터·server.properties는 보존합니다. 실행기 인스턴스는 실제 실행기 원본에 반영합니다.
- 적용 전 원본 백업과 변경 검사를 수행하고 실패하면 복구합니다. 서버 정지·파일 전송 완료 후 적용할 수 있습니다.
- 같은 Minecraft·로더 종류의 팩만 지원하며 로더 버전 자체는 교체하지 않습니다. config 덮어쓰기 기본 OFF, 클라이언트 전용 제외 기본 ON입니다. 추가 방식은 파일명이 다른 구버전 모드를 남길 수 있어 모달에 안내합니다.

## 폴더 ZIP 다운로드

- 파일 탭에서 월드 등 폴더나 현재 폴더를 ZIP으로 내려받을 수 있습니다. 압축 진행과 서버 전송 바이트를 하단에 표시합니다.
- 원격 서버에는 실행기 현재 원본과 **가장 최근 중앙 복사본** 선택지를 제공합니다. 중앙 복사본은 실행기 오프라인이어도 내려받을 수 있습니다.
- 복사 시각을 표시하며, 예전 복사본에 기록이 없으면 미기록으로 안내합니다. 복사본 압축과 다음 중앙 반영을 분리해 서로 다른 세대가 섞이지 않게 했습니다.
- 조회 권한 사용자도 파일 보기·다운로드·ZIP 준비가 가능합니다. 업로드·수정·삭제·팩 적용은 관리 권한이 필요합니다.
- 압축 전 최대 32 GiB·100,000항목을 지원합니다. 실행 중인 월드의 완전한 일관성이 필요하면 먼저 서버를 종료하세요. 브라우저 메모리에 전체 ZIP을 모으지 않고 스트리밍하며, 최종 파일 저장 상태는 브라우저에서 확인합니다.

## 테스트와 배포

- 예전 메뉴 이름을 찾던 사용자 역할·실행기 권한 테스트와 빠진 구형 실행기 API fixture를 현재 화면 구조에 맞췄습니다.
- 음악·팩·파일·권한 관련 백엔드 통합 기능 테스트와 14개 브라우저 테스트, 프런트 빌드를 실행합니다. 전체 테스트는 사용자 지시로 생략합니다.
- 운영 서비스·게임은 자동 재시작하지 않습니다. 기존 안정판 latest와 이미 게시된 자산을 유지하는 베타 릴리즈입니다.
