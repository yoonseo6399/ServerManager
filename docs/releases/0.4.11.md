# Server Manager 0.4.11

Discord 봇의 음악 기능과 코드 에이전트 기능을 추가했습니다.

- `/music`으로 YouTube 검색·재생, 대기열, 일시정지·재개, 이전·다음 곡과 음성 채널 입퇴장을 지원합니다.
- 음악 전용 채널과 고정 임베드 패널에서 현재 곡·썸네일·신청자·대기열을 표시하고 버튼으로 제어합니다. 재생 제어는 같은 음성 채널의 사용자로 제한합니다.
- `/agent`, `/sub-agent`와 작업별 Discord 스레드, 격리된 Git 작업 폴더를 사용하는 코드 에이전트를 추가했습니다.
- 관리 웹에서 Gemini 키별 프로젝트·한도와 GPT 메인 모델·작업 예산을 설정할 수 있습니다. API 키는 서버 측에 암호화해 저장합니다. AI 기능 사용에는 별도 제공자 API 비용이 발생할 수 있습니다.
- 관리 웹 재시작·실행기 재접속 후 이미 실행 중인 Minecraft의 게임 TCP 중계를 복구하도록 수정했습니다.

음악 및 에이전트 설정은 README와 `docs/discord-music.md`, `docs/luonnotar-agent.md`를 참고하세요. API 키와 음악 기능을 설정하지 않아도 기존 Minecraft 관리 기능을 사용할 수 있습니다.

이번 릴리스는 사용자 요청에 따라 자동·수동 기능 테스트를 생략했습니다. 프런트엔드·서버 빌드와 배포 자산의 해시·서명 생성만 진행했습니다. 실제 Discord 음성 재생과 AI 제공자 호출은 이번 배포 과정에서 확인하지 않았습니다.
