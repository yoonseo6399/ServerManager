# Server Manager 0.7.0-beta.5

로그 조회를 개선한 테스트용 베타입니다. beta.4의 Qwen 변경을 그대로 포함하며 stable 최신 버전은 0.6.3으로 유지합니다.

## 로그 조회
- 콘솔과 로그 파일 보기가 파일 전체를 줄 번호로 조회합니다. 스크롤하면 필요한 구간을 이어서 불러오고, 검색은 서버에서 파일 전체를 대상으로 수행합니다. 압축 로그(.gz)는 펼친 크기 128 MiB까지 조회합니다.
- 콘솔을 가득 채우는 `[MunitionRackDebug]` 모드 로그는 저장·표시하지 않고, 이전 로그 파일을 읽을 때도 건너뜁니다. 줄 번호는 이 줄을 제외하고 센 번호입니다.

## 업데이트
- 서버 화면에 "업데이트 대기 중"과 사유(예: 플레이어 연결 N개 종료 대기)를 표시합니다.
- 게임 상주 서비스(GAME_HOST) 교체가 대기에서 멈추던 문제를 수정했습니다. 게임·전송·접속이 없을 때 현재 연결로 자동 교체하고, 대기 중 신규 접속·시작은 잠시 막아 기존 연결이 끝나기를 기다립니다. 이전 버전 상주 서비스는 한 번의 수동 재시작이 필요할 수 있습니다.

## 검증
- 백엔드 테스트는 이 Windows 환경에서 beta.4와 동일한 102개가 실패합니다(심볼릭 링크 권한 등). 새로 추가한 로그 테스트는 통과했습니다.
- 추가한 호스트 교체 회귀 테스트(`HostReplacementTest`)는 작성만 했고 실행하지 않았습니다. 프론트엔드 빌드와 실제 화면 동작은 미검증입니다. 설치판·서명 검증 결과는 게시 후 개발 기록에 추가합니다.
