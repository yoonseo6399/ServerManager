# 0.6.3 — 실행기 업데이트 대상 확인 보완

0.6.2의 실행기 릴리즈 선택·베타 동의·상태/로그와 관리 앱/실행기 안정판 롤백을 포함합니다. 업데이트를 이미 받은 상태에서 다른 버전 요청이 실패하더라도, 활성화 확인과 적용 상태는 실제 대기 중인 매니페스트의 버전을 기준으로 처리하도록 보완했습니다.

실행기 카드의 **릴리즈 목록 새로고침 → 버전 선택 → 설치**를 사용하세요. 구형 실행기는 먼저 **원격 업데이트 요청**으로 최신 안정판을 받고 재연결해야 합니다. 베타와 낮은 안정판은 각각 별도 동의가 필요합니다. 기존 안전 적용과 서명·해시 검증을 유지합니다.

**안정판 롤백에는 0.6.2 이상 새 관리 앱 PKG와 실행기 ZIP 설치판을 한 번 적용해야 합니다.** 일반 JAR 업데이트는 부트스트랩을 바꾸지 않습니다. 이미 Qwen beta.1이면 업데이트/롤백 화면이 포함된 beta.2 설치판을 사용하세요. 이후 목록에서 안정판 0.6.3으로 돌아올 수 있습니다. 0.6.0 이상 안정판만 지원하며 월드·설정을 과거 상태로 복원하지 않습니다.

0.6.2 기능 검증은 관련 백엔드 33개·브라우저 4개, 실제 임시 부트스트랩 롤백/복구와 격리 웹의 공개 파일 다운로드·서명·계정 보존을 통과했습니다. 이번 대상 확인 수정은 관련 업데이트 테스트 23개를 통과했습니다. 전체 테스트·다른 OS·운영 설치는 요청대로 생략했습니다.
