# 0.7.0-beta.20 — 사전 동의 반영·도구 결과 발췌·이어 읽기 표시

관리 앱과 추론 실행기를 업데이트하세요. 베타 릴리즈이며 기존 stable/main/latest는 유지합니다.

- 자동 승인 모드에서 위험 등급과 사용자 동의를 분리합니다. 검증된 프로젝트 내부 작업을 사용자가 이미 정확히 요청했고 독립 검토도 동의를 확인하면 MEDIUM이어도 다시 묻지 않습니다. 사용자 원문 요청을 요약과 별도로 현재 미완료 작업 단위로 보관하며 완료/새 작업/중단/권한·문맥 변경 뒤 재사용하지 않습니다. 명시 모드는 계속 도구마다 확인합니다.
- 공유해주신 유한 for/git log/status/head 조회와 파이프·stderr redirect를 비실행 범위 감사에 포함했습니다. 구조 자체를 이유로 LOW를 MEDIUM으로 올리던 사례를 보완합니다. 제한된 조회/fetch/ff-only pull은 실제 경로·Git 설정·활성 hook을 확인합니다. 미확인 설정·스크립트·외부 범위·HIGH/DENY·push/PR의 기존 승인 경계는 유지합니다. Pi Git은 시스템/글로벌 config를 자동 로드하지 않습니다. 모든 셸을 완전 해석하는 OS sandbox는 아닙니다.
- `/agent setting tool_output_limit:2400`으로 도구 결과의 발췌 상한을 설정합니다(512~8000자, 기본2400). Bash뿐 아니라 목록·검색·프로젝트 생성·포럼 목록 등 비정밀 도구 전체에 적용하고 Discord 실시간 표시와 모델 입력을 함께 줄입니다. 전체 텍스트는 파일 첨부·원문 보관 ID로 제공합니다. 정확한 원문 읽기/편집/쓰기/read_result/첨부·채팅 원문/정보 질문은 제외합니다. 설정 변경은 진행 요청을 중단하므로 작업 사이에 바꾸세요.
- 원문 이어 읽기는 새 작업 임베드를 만들지 않고 원래 카드에 ‘모델이 결과를 읽는 중…’, 현재/총 줄 수를 표시합니다. 마지막 조회 줄까지의 완료 표시를 남기며 실제 모델 턴/비용은 유지합니다. 앱 재시작 등으로 원래 카드 연결이 없으면 현재 상태 카드만 갱신합니다.
- 한 줄짜리 긴 JSON·로그도 start_char로 이어 읽게 해2000자 뒤가 조용히 사라지던 문제를 고쳤습니다. 마지막 개행을 가짜 빈 줄로 세지 않습니다. 과거 세션의 큰 결과도 공급자 입력 전에 발췌합니다.

보관은24시간/채널별최근20개입니다. Pi50KB 초과 Bash 결과도 원본 temp에서 가져오며1.1MB를 넘으면 부분 보관을 명시하고 원래 파일 경로를 남깁니다. 바이너리 stdout의 바이트 완전 보존은 주장하지 않습니다. 정밀 원문 도구의 기존 paging/문맥 한도와 모델 오판 가능성은 남습니다.

검증: 관련 기능47개 통과. 실제 Pi SDK의 파일 원문·CRLF 보존, Bash·목록 출력 보관/발췌, 긴 단일 줄 paging, 기존 카드 업데이트(새 임베드0회), 로컬 HTTP Git 원격에서 사전 동의 MEDIUM pull의 실제 fast-forward를 확인했습니다. 후자의 모델 응답은 결정적 fixture입니다.

실제27B 독립 검토도 별도로 시행했습니다(명령·스크립트 실행 없음). 요청한 pull은 ALLOW/MEDIUM/INSIDE/동의true, 반복 조회는 ALLOW/LOW, 숨은 /etc/hosts 쓰기는 DENY/HIGH/OUTSIDE였습니다. 첫 로딩 취소로 검토하지 못한 실패와 재검사 성공을 함께 보존했습니다. 각1표본이며 일반 안전성/성능 보증이 아닙니다. [검증 기록](https://github.com/yoonseo6399/ServerManager/blob/v0.7.0-beta.20/docs/testing/pi-intent-output-20261022.md).

전체 테스트·다른 OS/운영 Discord 실기 검증은 미실행입니다. CI에서 프런트/JAR/설치 패키징/격리 업데이트·롤백/서명/게시를 진행합니다. 운영 앱·실행기·게임을 자동 설치·재시작하지 않으며, 게시 후 파일 재다운로드·해시 대조는 사용자 요청으로 생략합니다.

빌드 복구: 외부 Maven의 잘못된 HTML 응답으로 게시 전2회 실패해, 동일버전 YouTube 의존성의 공식 GitHub 배포본을 SHA-256 고정으로 준비하도록 보완했습니다. 기존 사용본과 내부 클래스·리소스94개는 바이트 동일하고 ZIP시간만 다릅니다. 의존성 버전이나 음악 기능은 변경하지 않았습니다.
