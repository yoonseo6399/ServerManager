# 0.7.0-beta.17 — Pi 기본 에이전트 엔진

- `/agent`의 기본 엔진을 **Pi SDK 1.3.0**으로 교체했습니다. 기존 자체 행동 loop·도구 JSON 해석·문맥 요약 대신 Pi의 공식 도구·부분 편집·세션·압축을 사용합니다. 모델 선택과 Discord 명령은 그대로입니다.
- 최초 요청 때 검증된 **Node24.22.1 + 고정 Pi 의존성**을 private profile에 자동 준비합니다. 인터넷과 추가 디스크 공간이 필요하며 이 Mac에서는 약375MB였습니다. 설치 진행 상태와 실패 로그를 제공합니다. Node를 따로 설치하거나 설정 파일을 직접 만들 필요가 없습니다.
- **관리 앱과 추론 실행기를 모두 업데이트하세요.** 구형 실행기는 Pi 요청을 거부하고 업데이트를 안내합니다. 도구는 관리 앱 컴퓨터에서 실행되며 원격 실행기는 모델 추론을 담당합니다. 일반 LLM 대화는 기존 도구 없는 방식입니다.
- Discord 권한·역할, 명시적/자동 승인, 독립 위험 검토와 경로 검사를 유지합니다. 검토 실패·거절·다른 사용자 승인·승인 후 파일 변경은 차단합니다. READ/EDIT 역할에는 임의 셸을 제공하지 않습니다. 소유자의 임의 셸은 명시적 승인 후 OS 사용자 권한으로 실행되며 OS 샌드박스는 아닙니다.
- 파일 읽기 원문을 별도 모델로 요약하지 않습니다. Pi의 읽기·부분 수정·검증을 사용하고, 긴 출력의 범위 제한은 SDK 정책을 따릅니다. 일반 답장·턴 카드·로그 스레드·실시간 출력·토큰/속도/메모리와 중지 버튼을 유지했습니다.
- 채널별 Pi 정식 세션을 재개하고 모델/컨텍스트 프로필을 바꿔도 보존합니다. 초기화는 프로젝트 설정을 유지한 채 새 세션을 만듭니다. 이전 UI 대화 원본은 private archive에 보존하고 최근 부분만 한 번 이관하며 부분 기록임을 명시합니다.
- 자동/수동 압축을 Pi에 맡깁니다. 설정한 압축 기준과 시스템/도구 공간을 반영한 유효 기준을 구분합니다. 압축할 내용이 없거나 압축에 실패한 경우 성공으로 표시하지 않습니다. 요약 정확성 자체를 보장하지는 않습니다.
- Strata가 남은 ready.json 때문에 시작하지 못하던 문제를 함께 수정했습니다. 실행마다 고유 준비 파일을 쓰고 자신이 소유한 실행 파일만 정리합니다. Flash-Next의 기존8K 제한은 유지합니다.

검증: 관련 기능34개(Pi SDK9·Strata 공급자4·실행기10·스트리밍4·문맥 예산5·Strata 준비 파일2), frontend/bootJar, runner setup·bootstrap. 실제 Qwen3.8 27B Q4_K_M/16K/Thinking off에서 read→bash→edit→read→bash 연쇄 호출이105.98초에 완료됐고, 지정 위치 삽입과 원문·CRLF·마지막 개행 보존을 바이트로 확인했습니다. 관측 생성 속도는 약12.6~13.1tok/s이며 전체 성능 보증은 아닙니다. Strata 시작/종료 반복과 READY_OK는 별도 수정 브랜치에서 실제 검증했습니다.

메모리: live 시험 중 압력 ‘주의’, 스왑 약6.37→9.23GiB 증가가 있었습니다. 시험 모델과 전용 Ollama를 종료했고 기존20GiB wired 한도는 사용자 요청대로 유지했습니다. 앱은 OS 메모리 한도를 변경하지 않습니다.

사용자 요청대로 전체 테스트·다른 OS 실행은 생략했습니다. 실제 Discord 네트워크/승인 버튼, 여러 컴퓨터 Pi 전체 연결, Flash-Next 전체 Pi 행동 loop, 이미지 인식은 검증/구현 범위에 포함하지 않았습니다. 운영 서비스는 자동 재시작하지 않았습니다. 베타이며 stable/latest는 기존0.6.3을 유지합니다. 상세 구조와 실제 주입 지시문은 `docs/architecture/pi-agent-runtime.md`, `agent-context.md`, `agent-context-prompts.md`를 참고하세요.
