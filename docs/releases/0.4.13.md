# Server Manager 0.4.13

- 웹 화면 전체에서 브라우저 뒤로가기·앞으로가기가 동작합니다. 서버 선택, 탭, 파일 폴더, 파일 편집기를 이동한 순서대로 되돌아가고, 서버 만들기·모드팩 가져오기·모드 변경 확인·시도 로그·로그 상세 창은 뒤로가기로 닫힙니다. 저장하지 않은 변경이 있으면 기존 확인 창이 먼저 나타납니다.
- 서버가 실행 중이어도 모드 화면에서 모드 목록, 의존성, 경고를 볼 수 있습니다. 켜기·끄기, 문제 모드 찾기, 버전 링크 연결 같은 수정은 서버를 정지해야 가능하며, 화면에 안내가 표시됩니다.
- 모드 목록은 "모드 목록 불러오기" 버튼 없이 모드 탭을 열면 자동으로 불러옵니다. 서버가 정지되면 목록을 한 번 다시 불러옵니다.
- 서버가 원격 실행기에서 실행 중일 때 표시되는 목록은 관리 컴퓨터에 있는 복사본 기준입니다.
- 계정·패스키·기존 서버 폴더·월드·모드는 유지됩니다. 이미 게시된 버전의 설치 파일은 교체하지 않습니다.
