# Server Manager 0.4.14

- Discord `/local-llm`에서 Qwen3 14B·30B를 일반 대화용으로 호출할 수 있습니다. 기존 최고 관리자 역할만 사용할 수 있고 답변은 요청자에게만 표시합니다. 코딩 에이전트·파일·실행 도구와 분리되어 있습니다.
- Ollama는 관리 앱과 같은 컴퓨터에서 실행합니다. 기본 모델 태그는 `qwen3:14b`, `qwen3:30b`이며 설치된 태그를 환경변수로 바꿀 수 있습니다. 모델은 자동 설치하지 않습니다.
- 로컬 모델은 한 번에 1개 요청, 입력 6,000자·최대 출력 2,048토큰·3분 제한을 적용합니다. 기본 사고 출력 요청은 꺼져 있고, 긴 답변은 첨부 파일로 보냅니다. 출력 한도에 도달하면 미완성 가능성을 표시합니다.
- 게임 주소·중계 화면에서 등록된 다른 실행기를 TCP 중계 컴퓨터로 선택할 수 있습니다. 해당 컴퓨터에서 로컬 수신을 허용한 뒤 공유기·방화벽·DNS를 해당 컴퓨터로 설정해야 합니다.
- TCP 경로는 플레이어 → 중계 실행기 → 관리 Mac → 게임 실행기입니다. 관리 Mac을 계속 경유하며, 실행기의 연결이 끊기면 중계 연결을 닫고 현재 설정에 따라 재연결합니다. 다른 컴퓨터의 중계는 Sable UDP와 동시에 사용할 수 없습니다.
- 0.4.13의 기존 뒤로가기·앞으로가기와 실행 중 모드 조회 기능을 유지합니다. 뒤로가기 기능을 새로 변경하지 않았습니다.

사용 방법: `docs/luonnotar-agent.md`, `docs/tcp-relay-runner.md`.
실제 Qwen 모델 추론·Discord 실연동·서로 다른 컴퓨터의 공개망 접속은 이 환경에서 검증하지 않았습니다.
