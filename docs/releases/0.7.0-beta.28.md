# Server Manager 0.7.0-beta.28

## 파일·모드 업로드
- 관리웹까지는 1 MiB씩 분할 전송하고, 실행기에 반영하는 과정은 작업 ID를 가진 백그라운드 작업으로 분리했습니다. 긴 단일 요청의 504 시간 초과 뒤 다음 파일까지 409로 실패하던 흐름을 개선합니다.
- 업로드 진행 상태와 오류 사유를 표시하고, 수신·대기·실행기 전송 중에는 파일별로 취소할 수 있습니다. 취소 시 기존 파일을 보존하고 임시 쓰기를 정리합니다.
- 파일 교체가 시작된 단계에서는 취소할 수 없음을 명확하게 표시하고 실제 완료 결과를 기다립니다.
- 페이지를 새로고침해도 이미 접수된 백그라운드 작업의 상태가 복원됩니다. 이전 페이지에서 브라우저 전송이 끝나지 않은 파일은 취소하며, 다른 탭의 업로드는 유지합니다.
- 같은 서버의 업로드는 순서대로 반영합니다. 작업 소유권·현재 서버 변경 권한·CSRF·경로/크기/디스크 제한을 유지하며 권한이 회수되면 반영 전에 중단합니다.
- 실행기는 파일 교체 응답을 먼저 보내고 복구용 서버 복사본 준비를 별도 작업으로 처리합니다.

## 로그 보기
- 위로 스크롤하면 자동 추적을 멈추고 읽는 위치와 표시 구간을 유지합니다.
- 블록 보기·원문 보기 모두 **아래로 이동** 버튼을 추가했습니다. 최신 로그로 복귀하거나 실시간 구간의 맨 아래로 내려가면 자동 추적을 재개합니다.
- 블록의 임시 높이 때문에 최신 위치를 잘못 계산하던 문제를 수정했습니다.

## 적용과 검증 범위
- 업로드 개선을 모두 적용하려면 **관리웹과 실행기를 함께 업데이트**하세요.
- 브라우저 새로고침은 접수된 작업을 유지하지만, 관리웹 프로세스 자체가 재시작되면 미완료 작업을 중단으로 기록합니다. 반영 도중 중단됐다면 파일 상태를 확인한 뒤 재업로드하세요.
- 개별 mrpack 미리보기·신규 서버 ZIP 가져오기는 기존 전용 절차를 사용합니다.
- 관련 기능·권한·모바일·회귀 검증 결과는 개발 노트에 기록합니다. 전체 테스트와 실제 외부 프록시의 장시간 업로드 시험은 실행하지 않았습니다.
- 기존 stable 릴리즈와 설치된 서버 파일은 변경하지 않습니다.
