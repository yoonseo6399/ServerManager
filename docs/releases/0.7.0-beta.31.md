# Server Manager 0.7.0-beta.31

## 로그인·차원 이동·청크 전송 버스트 완화

Beta30의 작은 TCP 조각 병합 수정에 더해, 정상적인 대량 전송도 여유 있게 처리하도록 기본 한도를 조정했습니다. 로그인뿐 아니라 차원 이동과 청크 전송도 같은 중계 경로를 사용합니다.

- endpoint 버퍼: 접속당16MiB, 역할별 전체128MiB. 필요한 만큼만 사용하며 무한 적재하지 않습니다.
- 공통 터널 송신: 전체16MiB/접속당4MiB, 큐4096항목. 접속별 순서와 공정 처리를 유지합니다.
- 쓰기 정체 제한:10초에서60초로 완화했습니다. Minecraft 자체 keep-alive와 기존 읽기 제한은 별개입니다.
- 작은 조각은 최대32KiB 묶음으로 합치며, beta29의32개 조각만으로 접속을 끊던 회귀는 제거됐습니다.

## 검증·적용

6MiB/작은 조각24,576개와 표식의 전체 바이트 일치·메모리 회수, 실제 암호화 TCP의64MiB 미수신 접속 격리 및 다른 접속 유지, EOF/UDP/음성/상주 서비스 관련70개가 통과했습니다. 실제 Minecraft 차원 이동의 모든 모드/환경을 재현했다고 주장하지 않습니다.

**중계·게임 실행기의 GAME_HOST도 beta.31로 업데이트해야 합니다.** 게임을 정상 종료한 뒤 상주 서비스 교체와 재시작이 필요합니다. 이전 beta30 자산은 그대로 보존합니다. 실제 회선 단절과 beta29 이전의 동시 끊김 원인은 별개입니다. 전체 suite·다른OS 실기·공개 자산 재다운로드 해시 비교는 생략합니다.
