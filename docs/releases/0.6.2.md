# 0.6.2 — 실행기 릴리즈 선택과 안정판 롤백

**실행기·네트워크 → 서버 실행기**의 카드에서 릴리즈 목록을 조회하고 설치할 버전을 선택할 수 있습니다. 안정판 실행기도 별도 베타 동의가 있으면 선택한 베타를 받습니다. 현재 STABLE/BETA 채널·대상 버전·다운로드 진행률·검증·대기 사유·실패 로그를 표시합니다. 기기 등록자 또는 소유자와 최근 패스키 인증이 필요합니다.

구형 실행기는 먼저 **원격 업데이트 요청**으로 최신 안정판을 받고 재연결해야 선택 명령을 지원합니다. 자동 업데이트의 채널 규칙은 유지하며, 수동 선택 대기는 자동 확인으로 덮어쓰지 않습니다.

관리 앱과 실행기에서 **0.6.0 이상 낮은 안정판으로 롤백**할 수도 있습니다. 별도 롤백 동의·확인 후 정확한 대상의 서명·해시·버전·호환성을 검사합니다. 승인 없는 낮은 버전과 낮은 베타는 거부합니다. 재시작 후 선택한 버전을 유지하고 시작 실패 시 적용 전 버전으로 복구합니다. 프로필·월드를 과거 시점으로 복원하는 기능은 아닙니다.

**롤백은 이번 관리 앱 PKG와 실행기 ZIP 설치판을 한 번 적용해야 합니다.** JAR 자동 업데이트는 부트스트랩을 교체하지 않으며, 지원하지 않는 설치판은 화면에 안내하고 롤백을 막습니다. 기존 0.7.0-beta.1 사용자는 업데이트 화면이 포함된 새 0.7.0-beta.2 설치판을 사용하세요. Qwen 새 하네스는 별도 베타에 유지합니다.

Mac에서 관련 백엔드 33개·브라우저 4개, 프런트엔드/bootJar 빌드, 실제 관리 앱/실행기 부트스트랩의 승인 롤백·재시작 유지·변조 거부·무승인 차단·실패 복구를 통과했습니다. 격리된 실제 관리 웹에서 패스키·롤백 동의·공개 GitHub 다운로드·서명·해시·계정 보존도 확인했습니다. 전체 테스트와 다른 OS 검증은 사용자 요청으로 생략했습니다. 운영 앱은 교체하지 않았습니다.

상세 사용법: [실행기 업데이트와 롤백](https://github.com/yoonseo6399/ServerManager/blob/v0.6.2/docs/runner-release-updates.md).
