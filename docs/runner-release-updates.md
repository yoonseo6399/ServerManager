# 실행기 릴리즈 선택과 안정판 롤백

관리 웹 **실행기·네트워크 → 서버 실행기**에서 각 실행기의 현재 버전·STABLE/BETA 채널과 업데이트 상태를 확인한다. 실행기 카드의 **릴리즈 목록 새로고침 → 버전 선택 → 선택한 릴리즈 설치**로 요청한다. 베타 설치와 낮은 안정판 롤백은 각각 별도 동의가 필요하다. 기기 등록자 또는 관리 웹 소유자만 요청하며 최근 패스키 인증을 확인한다.

## 처음 적용할 때

- 구형 실행기는 릴리즈 선택 명령을 이해하지 못한다. 먼저 **원격 업데이트 요청**으로 최신 안정판 제어 계층을 받고, 재연결 후 선택 기능이 활성화되면 베타를 선택한다.
- 롤백에는 새 부트스트랩이 필요하다. **관리 앱 PKG와 실행기 ZIP 설치판을 한 번 적용**해야 한다. 일반 JAR 자동 업데이트는 부트스트랩을 교체하지 않는다. 지원 여부를 화면에 표시하며 미지원이면 롤백을 거부한다.
- 이미 0.7.0-beta.1을 사용 중이라면 새 기능이 포함된 0.7.0-beta.2 설치판으로 올려서 사용한다. beta.1에는 이 화면과 롤백 처리가 없다. 게시된 beta.1 파일은 변경하지 않는다.
- 별도 config 파일 편집은 필요하지 않다. 기존 등록·계정·서버 프로필을 사용한다.

## 상태와 적용

대상 버전·다운로드 바이트/백분율·서명 검증·대기 사유·실패 원인과 구성요소별 로그를 표시한다. 기존 안전 적용 절차를 유지하며 실행 중인 게임과 파일 전송을 강제로 끊지 않는다. 구형 게임 실행 방식 등으로 적용할 수 없으면 기다리는 이유를 표시한다. 대기 중인 수동 선택은 주기적 자동 확인으로 덮어쓰지 않는다.

안정판 실행기에서도 베타 동의가 있는 수동 요청은 해당 버전을 정확히 검증·다운로드한다. 자동 업데이트는 현재 실행 버전의 STABLE/BETA 규칙을 계속 따른다. 선택 가능한 목록은 최근 공개 릴리즈 100개이며, 실제 실행기에서도 다시 공개 여부·서명·해시·버전·호환성을 검사한다.

## 안정판으로 돌아가기

낮은 버전에는 `롤백` 표시가 붙는다. 롤백 동의 후 확인창에서 승인하면 그 안정판을 적용한다. 기존 상주 게임 서비스와 호환되는 **0.6.0 이상 안정판**으로 제한하며, 낮은 베타 버전·같은 버전·실패 이력이 있는 버전·업데이트 파일이 없는 버전은 적용하지 않는다.

이 기능은 앱/실행기 버전을 바꾼다. 월드와 설정을 과거 시점으로 되돌리지 않으며 구버전이 새 설정을 모두 이해한다고 보장하지 않는다. 계정·월드 등 중요한 데이터는 별도로 보관해야 한다. 자동 업데이트 설정은 바뀌지 않는다. 관리 앱은 자동 적용 설정을 끌 수 있고, 실행기는 기존 6시간 주기의 안정판 자동 확인을 유지한다.

승인은 정확한 안정판 대상에만 적용되고 적용 후 소비된다. 재시작 후에도 승인한 낮은 버전을 유지하되 저장된 JAR의 서명·해시를 다시 검사한다. 시작 검증에 실패하면 적용 전 버전으로 복구한다.
