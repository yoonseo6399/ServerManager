# Pi 개인 비서 도구

관리 앱과 추론 실행기를 모두 Beta18 이상으로 업데이트한다. 도구·파일은 관리 앱 컴퓨터에서 실행한다.

## 창 크기와 요청 시간

- 이번 요청만16K: `/agent run prompt:요청 window:16384`
- 채널 기본16K: `/agent context action:configure window:16384`
- 관리 웹 ‘로컬 LLM’ → ‘추론 요청 제한 (분)’:1~240분, 기본20. 다음 모델 요청부터 적용한다. 셸 명령 실행 시간과 여러 턴의 총 시간은 별도다.
- 실제 추론 컴퓨터의 메모리 압력이 ‘위험’이면 모델 호출을 중단하고 ‘위험을 감수하고 재시도’를 표시한다. 해당 호출 한 번만 감시 우회하며 파일·명령 승인은 그대로다.

## 질문과 승인

질문 선택지 이외의 내용은 같은 채널에 직접 입력한다. 실행 승인 카드에는 버튼 외에도 ‘실행해’, ‘하라고’, ‘허용’, ‘거절’로 답할 수 있다. 현재 표시된 작업 한 건에만 연결되며 정보 질문 답변 자체가 포괄 실행 허가는 아니다.

스크립트를 실행할 때는 실제 진입점 원문과 해시를 독립 모델에게 검토시키고 바뀌면 차단한다. 검토되지 않은 의존성/큰 파일/동적 코드 등을 완전히 안전하다고 보증하지 않는다. 위험/불확실한 실행은 자동 승인하지 않는다. DENY는 실행되지 않았다는 사실과 이유를 모델에게 전달한다. ASK는 이유와 명시 승인 카드를 표시한다.

## 서로 다른 Discord 서버의 정보 사용

봇이 **정보 제공 서버와 정보 사용 서버 양쪽에 있어야 한다.** 양쪽에 필요한 봇/에이전트 역할을 먼저 설정한다. 출처 설정은 정보 제공 서버에서 해당 최고 관리자가 실행한다.

1. 정보 제공 서버에서 출처 등록: `/agent history action:allow source:#자료포럼`
2. 정보 사용 서버에서 `/agent channel`로 비공개 에이전트 채널 생성, 채널 ID/링크 복사.
3. 정보 제공 서버에서 위임: `/agent history action:grant source:#자료포럼 target:정보사용채널ID users:사용자ID`
4. 정보 사용 채널에서 루오에게 허용 출처 목록/게시글/내용 조회 요청.
5. 전달 채널 철회: `/agent history action:revoke source:#자료포럼 target:정보사용채널ID`
6. 출처 자체 제거: `/agent history action:remove source:#자료포럼`

사용자는 ID나 멘션을 쉼표로 구분해 지정한다. 현재 에이전트 채널 소유자가 포함돼야 하며 실제 요청자의 서버·채널·ID를 매번 확인한다. 출처만 등록하면 아무 전달 대상도 허용되지 않는다. 출처의 제공자 관리자·봇 읽기 권한이 유지되어야 한다. 수신자가 제공 서버 멤버일 필요는 없다. 정보 조회는 모델 도구로 가능하지만 ACL 변경은 사용자 명령만 가능하다.

포럼 허용은 해당 게시글에 적용된다. 활성 목록은 캐시 일부, 보관된 공개 게시글은 최근 한 페이지다. 내용은 한 번에 최대50개 메시지/40K자이며 첨부를 자동 다운로드하지 않는다. **정보 사용 채널을 볼 수 있는 사람과 Discord 관리자도 전달된 답변을 볼 수 있다.** 철회는 다음 조회부터 적용되며 이미 읽은 정보는 소비 채널에서 문맥을 초기화해야 한다.

## 예약과 파일 변경

‘내일 오후3시에 이 프로젝트를 점검해줘’처럼 요청하면 schedule_task로 일회성 예약을 만들 수 있다. 시각/시간대가 불명확하면 먼저 확인한다. 등록은 명시 승인이 필요하다. `/agent schedules`에서 조회, `cancel:예약ID`로 취소한다. 앱/봇이 켜져 있어야 하며15분 초과 지연이나 재시작 중 실행중이던 예약은 조용히 재실행하지 않는다. 미래 파일/셸 권한을 미리 포괄 승인하지 않는다.

파일 변경은 기본 diff와 ‘자세히’의 전후 원문 첨부로 확인한다. 자세히는 소유자·채널·문맥에 묶여10분간 제공된다. 임의 Bash의 프로젝트 밖 모든 변경이나 바이너리/큰 파일까지 자동 추적하지는 않는다. 자세한 관측 범위는 [Pi 구조](architecture/pi-agent-runtime.md)를 참고한다.


### 도구 결과 길이와 이어 읽기

`/agent setting tool_output_limit:2400`으로 도구 결과 발췌를512~8000자 사이에서 조절합니다. 초과 결과는 원문 파일로 첨부·보관하고 모델에는 일부 발췌와 이어 읽기 ID를 줍니다. 정확한 파일 읽기·편집·질문 답변에는 적용하지 않습니다. 이어 읽기는 원래 작업 임베드에 현재/총 줄 수만 갱신합니다. 설정 변경은 진행 중 작업을 중단하므로 작업 사이에 바꾸세요.

자동 모드(`/agent setting explicit_permission:false`)에서는 같은 프로젝트의 정확한 작업을 이미 명시한 것으로 확인되면 보통 위험도 재승인 없이 진행할 수 있습니다. 시스템/외부·미확인 스크립트·푸시/PR 등은 별도 검토/승인 경계를 유지합니다. 명시 모드는 도구마다 확인합니다.
