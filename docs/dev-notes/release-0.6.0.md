# release/0.6.0

## 승인 범위
- 사용자 요청에 따라 설정 메뉴 정리, Gemini 메인 모델, 개인 Google 읽기 전용 연결, 관리 로그, 직접 TCP 중계, 게임 유지 업데이트, 제한된 Qwen 파일 비서를 통합한다.
- 테스트 설계·코드 검토는 주 에이전트, 실제 테스트 실행은 담당 서브에이전트가 수행한다.
- 2026-10-16 후속 지시: 다른 운영체제 실행 검증은 생략한다. Mac 검증에 집중하며 다른 운영체제는 미검증으로 명시한다.
- 운영 앱·실행기·Minecraft를 재시작하거나 공유기·DNS를 변경하지 않는다. 공개 릴리즈 게시와 운영 환경 적용은 구분한다.

## 현재 통합
- `feat/direct-relay-settings-ui`의 `fd13db1`까지 포함: 설정 분리, Gemini/Google UI, 직접 중계 전환, 포트 안내, 실행기·관리 앱 업데이트 상세 표시.
- `feat/system-log-viewer`의 `c48193a` 포함: 소유자 전용 메모리 로그와 접근 제어 회귀 테스트.
- 각 병합 뒤 서버 컴파일·프런트 빌드 통과 보고를 받았다. 릴리즈 전체 검증 완료를 의미하지 않는다.
- Claude의 직접 중계·상주 호스트 기반과 Mac 보완은 `feat/host-update-validation`의 `955d20a`까지 통합했다. `a70fbfc`는 TCP 분할 응답을 끝까지 읽도록 회귀 테스트만 수정한다.
- `feat/qwen-assistant-harness`의 `5e76b14` 및 소유자 화면 연결 `2923d68`을 통합했다.
- 최종 통합 전체 백엔드 XML 기준 377개: 369 통과, 1 실패, 7 제외. 실패는 연결 종료 전에 남은 TCP 응답을 읽지 않은 테스트 가정이었다. `a70fbfc` 수정 후 중계 테스트 13개가 통과했다. 런타임 코드 변경은 없다. 최종 게시 CI의 전체 결과는 별도로 확인한다.
- 최종 설정·비서 화면 테스트 11개 통과. 기존 탐색 테스트는 1 통과/2 실패: 파일 패널 뒤로가기 실패는 기존 v0.4.13 기준선과 동일하며, 다른 하나는 변경 전 메뉴명을 찾는 오래된 선택자다. 요청에 따라 뒤로가기 새 구현은 추가하지 않았다.
- 실제 0.6.0 JAR를 임시 데이터·홈으로 시작해 전체 Spring 서비스 구성을 확인했다. 세션 API는 버전 0.6.0/초기 설정 필요를 반환하고 관리자·Google 경로의 익명 접근은 401이었다. 테스트 프로세스·임시 데이터는 정리했다.
- 최종 안내 문구 `6645f7d`까지 병합 후 컴파일·프런트 빌드 통과. 중계 실행기만 화면의 TCP 포트포워딩을 필요로 한다는 점을 설치 ZIP 안내에 반영한다.

## 게시 전 필수 확인
- 호스트 연결 실패나 호환성 실패를 정상 시작으로 보고하지 않아야 한다. 기존 게임·중계가 있으면 안전하게 대기 또는 기존 제어 계층으로 롤백한다.
- 관리 제어 연결 재접속이 게임 데이터 경로를 끊지 않아야 하며, 권한 철회는 실제로 차단해야 한다.
- Qwen은 지정 파일·승인된 변경만 반영한다. 파일 변경 경쟁, 링크, 취소·만료·재사용 승인, 소유자 접근 제어를 확인한다.
- 파일 편집 UI를 실제 소유자 메뉴에 연결하고, 정보 전송 동의와 최종 반영 승인을 분리한다.
- 최종 소스의 전체 백엔드·프런트·관련 브라우저 테스트, 패키징·부트스트랩·서명 검증을 완료한다. 실패/미실행은 구분해 기록한다.
- `VERSION`, 한국어 릴리즈 노트 및 개발 이력을 정리한 뒤 새 태그로 게시한다. 기존 공개 버전 파일은 바꾸지 않는다.

## 현재 미검증
- 실제 외부 인터넷·공유기를 통한 여러 컴퓨터 직접 중계.
- 실제 Qwen 추론 품질·속도·메모리와 실제 Google OAuth 연결 및 Discord 사용자 상호작용.
- 다른 운영체제 실행. 해당 생략은 사용자의 최신 지시다.
- 브라우저 뒤로가기는 기존 구현을 확인하는 범위이며 새 구현을 추가하지 않는다.
