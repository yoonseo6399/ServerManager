# Beta 11 agent reliability

- 기준: 게시된 `v0.7.0-beta.10` / `84cfa9f`. `origin/main`은 아직 Beta 9여서 게시 태그에서 분기했다.
- Beta 10 이력: `694047b` Discord 모듈·권한 서비스, `8ec97d1` 기능 폴더 이동(패키지 유지), `28c4540` Minecraft 모듈·권한 경계. `docs/architecture/`와 테스트 가이드를 확인했다.
- 단독 작업. 기존 DiscordModule/PermissionService 및 승인 경계를 유지하고 `agent/`, `ai/`, 필요한 실행기 프로토콜만 확장한다.
- 범위: 8K/16K 실행 프로필과 일관된 입력·출력 예산; 요구사항/계획 보존; 결과별 완료 근거와 재조회 검증; 반복·미호출 감지; 읽기 원문과 큰 결과 보관; 검색/부분 수정/CRLF와 Git 비밀 경로 우회 수정.
- 실측 전제: 현재 24 GiB Mac의 Qwen3 30B는 16K 설정에서 입력 10,852토큰 처리 및 생성이 가능했지만 압력 경고. 32K는 임계 압력으로 중단, 64K 미실행. 기본 8K 유지, 16K 선택 시 경고. 모델 최대치와 앱 실행창은 별개다.
- 공식 Ollama `tools`/`message.tool_calls`/`role:tool` 경로를 실제 Discord·실행기 대화에 연결했다. 역할별 기본 도구와 추가 도구 선택을 분리하고, 문자열 JSON을 실행으로 해석하지 않는다. 기존 권한·독립 위험 검토·사람 승인은 그대로 거친다.
- 읽기 원문 기본 보존, 읽은 뒤 부분 수정, 저장 지문·완료 근거·재조회, 변형된 동일 조회 반복 제한을 추가했다. 실제 저장한 변경 사실은 요약과 별도로 고정하여 수정 후 과거 문자열 부재를 실패로 오판하는 경우를 줄인다.
- 문맥 프로필과 작업 계획은 별도 비공개 파일에 저장한다. 기존 저장 형식과 8K 롤백·재설정 epoch를 보존하며 원격 실행기의 새 capability 없이는 조용히 기능을 낮추지 않는다.
- 검증: 기능 회귀 168개 중 160개 통과·8개 opt-in 건너뜀·실패 0. 실제 14B 임시 파일 시험과 원문은 `docs/testing/beta11-validation.md`, 요약은 `beta11-results.json`에 기록한다. 개발 중 실패도 로컬 증거에 보존한다.
- 같은 소스 14B/8K 최종 비교: 공식 방식은 원문 보존·수정·검증·보고를 187.1초에 통과했다. JSON도 파일 수정·보존은 성공했지만 완료 근거 누락과 반복으로 254.3초에 중단됐다. 각각 한 과제 한 번의 결과로 공식 방식을 기본 채택하며 일반 성능 순위는 주장하지 않는다. 비교 후 중단 보고의 실제 변경 표시만 추가 보완했고 관련 21개 회귀를 다시 통과했다.
- 미검증: 전체 테스트(사용자 요청으로 생략), 다른 OS, 실제 Discord 상호작용, 원격 설치 후 양단, 이번 하네스의 다른 모델·장시간 품질·16K 전체 입력. 반복 제한과 영수증은 모델의 모든 의미적 오류를 증명하거나 해결하지 않는다.
- 릴리즈 파일/VERSION은 작업 브랜치에서 변경하지 않는다. 최신 사용자 요청에 따라 `release/0.7.0-beta.11`에서 통합·서명·게시하며 stable main은 기존 Beta 릴리즈 관행대로 분리한다. 운영 앱·실행기·게임호스트 교체는 하지 않는다.
- 릴리즈 문구: 로컬 에이전트의 공식 도구 호출과 8K/16K 실행 프로필, 계획·실제 변경 보존, 원문을 지키는 부분 수정·검증 및 반복/허위 완료 제한을 추가했습니다. 기능별 회귀와 실제 14B 파일 작업 비교를 수행했으며 나머지 한계는 검증 문서에 명시했습니다.
- 게시: `v0.7.0-beta.11` / `d13d101`, 서명 CI `39096882468` 성공(전체 테스트 생략 확인). https://github.com/yoonseo6399/ServerManager/releases/tag/v0.7.0-beta.11
- 후속 공개 검증: 9개 자산의 GitHub SHA-256 digest와 다운로드한 SHA256SUMS 일치. 실제 다운로드 JAR·manifest·signature의 해시/크기/버전과 저장소 고정 Ed25519 공개키 서명 일치. stable latest는 v0.6.3 유지. Beta 12의 명령 실행 실패 재현은 이 파일 편집 비교의 일반화 한계를 별도로 기록한다.
