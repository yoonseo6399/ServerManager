상태: 빠른 종료 세션 회귀 포함 대상28개 통과, 서명 게시 준비
# release/0.7.0-beta.33

- 공개 beta32 소스060ac42와 게시 전 검토에서 추가한7b59fd7을 기반으로 새 버전을 만든다. beta32 자산·태그와 기존 안정판은 변경하지 않는다.
- 같은 Process에 대해 시작 시 로그 식별값을 한 번 만들고 재사용한다. JVM 종료로 Process.info가 조회 불가능해진 경우의 예외·식별값 경합을 처리한다.
- 명시적으로 info 조회가 실패하는 프로세스를 모사한 회귀를 추가했고, 기존 로그/전체 검색/권한/원격 읽기/실행 중 차단/런타임 백업·실패 복구를 포함한 대상28개가 통과했다.
- 프런트·기타 기능은 beta32와 동일하다. 기존 브라우저19개·TS/Vite·공식 Mojang 격리 런타임 교체·보안핀11개·실행기 설치 검증 결과를 유지한다. 패키징·부트스트랩·서명은 beta33 CI에서 다시 수행한다.
- 전체 회귀·다른OS 실행·실제 모드 로더 교체·실제 월드 로드는 미실행이다. 운영 관리웹/실행기/Minecraft/계정/월드/모드는 변경하지 않는다.
- 공개 후 재다운로드 해시 검사는 하지 않고 GitHub 게시 메타데이터와 CI 서명 결과를 확인한다.
