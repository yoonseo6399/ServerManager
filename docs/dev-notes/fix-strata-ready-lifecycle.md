# fix/strata-ready-lifecycle

- 기준 v0.7.0-beta.16. Strata가 `--ready-file already exists`로 exit2 종료한 실제 로그 확인.
- 이전 취소 시험의 ready.json이 10:26에 남았고, 사용자 호출에서 재사용해 거부됨. 모델 메모리·Metal 호환·권한 승인 문제가 아니라 실행 준비 파일 수명 누락.
- 현재 컴퓨터에서는 해당 PID가 사라지고 18080 수신 없음, 서비스 잠금 획득 가능을 확인한 뒤 stale 파일을 보관 이름으로 옮김. 설정/모델/게임은 변경하지 않음.
- 제품 수정: 매 실행마다 private runtime/run-<무작위>/ready.json 사용. 충돌을 피하고 소유 프로세스가 모두 종료된 후 해당 실행의 준비 파일과 빈 폴더만 정리. 이전 실행/다른 프로세스의 파일은 건드리지 않음.
- 단위 5개 통과(StrataLaunchFiles 2 + StrataLlm 3). 전체 테스트는 생략.
- 하네스 검토·수정이 끝나기 전 릴리즈하지 않음(사용자 추가 지시).

- 실제 Mac에서 stale 실행 파일을 남겨 둔 채 3회 start→ready→stop, 세 번 모두 다른 준비 파일 경로, 종료 후 자기 폴더 정리, 마지막 실제 READY_OK 생성 통과(20초). 테스트 코드의 Path가 Iterable인 집합 비교 오류를 수정한 뒤 재실행했으며, 처음 실패를 모델 실행 실패로 분류하지 않음.
