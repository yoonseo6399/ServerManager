# 관리 앱 로그 조회
- 기준: origin/main에서 시작하여 origin/release/0.5.1(ad2bc9c)을 fast-forward로 포함.
- 현재 프로세스의 INFO/WARN/ERROR 진단을 최대 2,000개 보관하고 소유자 전용 /api/admin/system-logs로 조회한다.
- 원본 로그 파일, 예외 스택, MDC, 에이전트/인증 제공자 로그는 노출하지 않는다. 민감한 필드가 보이는 행은 숨기고 URL 경로와 긴 식별자를 가린다. 이 필터는 임의 텍스트에서 모든 개인정보를 식별한다는 보증이 아니다.
- 시간·수준·구성요소·문자열 필터, 순번 커서, 버퍼 유실 및 프로세스 변경 감지를 제공한다. 재시작 전/수집 시작 전 로그는 제공하지 않는다.
- 상위 에이전트가 설계한 검증: 커서 페이지 누락/중복, 필터 후 커서 진전, 버퍼 회전, 재시작 커서, 크기 제한, 비밀/URL 숨김, owner-only 접근 및 no-store.
- 테스트는 하위 에이전트가 수행할 예정이며 아직 통과로 주장하지 않는다.
