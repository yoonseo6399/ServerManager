# feat: 실행기 원격 재시작

- 관리 웹 `POST /api/runners/{id}/restart` (패스키 최근 인증, 기기 등록자·소유자만). 실행기가 `restart-capability: RESTART_V1`을 광고한 경우에만 `restart-request`를 보낸다. 이 기능이 없는 기존 실행기는 한 번 업데이트해야 하며, 그때까지는 409로 안내한다.
- 실행기는 즉시 판정하고 `restart-result`(ACCEPTED/REFUSED+사유)로 답한다. 기다리지 않는다. 거부 사유: 중계 접속 중, 구 방식 게임, 서버 준비·설치, 전송, 파일 인계 대기, 호스트 교체 중, 호스트 연결 불가.
- 수락하면 전송을 멈추고 700ms 뒤 종료 코드 75로 끝난다. 기존 `RunnerBootstrap`이 같은 버전으로 다시 시작한다. 상주 서비스가 소유한 게임은 유지된다.
- 임의 명령 실행이 아니다: 보내는 것은 고정 메시지뿐이며 감사 로그에 기록된다.
- 상태: 컴파일만 확인. 테스트 미작성·미실행, 프런트엔드 미빌드. 수동 확인: 새 버전 실행기에서 버튼 → 재연결, 게임 실행 중 재시작 시 게임 유지, 접속 중 거부 메시지.
