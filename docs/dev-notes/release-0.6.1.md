상태: 게시 완료 — 최신 안정판 0.6.1, 서명·공개 파일 검증 완료
# 0.6.1
- 0.6.0 기반 릴리즈 선택 수동 업데이트. Qwen 프로젝트 하네스는 0.7.0-beta.1로 별도 게시.
- 관련 백엔드 19개·브라우저 1개·프런트/JAR 빌드·임시 부트스트랩 통과. 전체 테스트·다른 OS 생략.
- 서명 CI 및 공개 산출물 확인 후 게시 완료를 기록한다.
- 최초 미게시 CI는 수동 선택 보존 보완을 위해 취소했다. 게시 단계 미실행을 확인한 뒤 같은 미게시 태그를 수정 커밋으로 갱신한다.
- 최종 게시 커밋 bcb257c, CI 38884372302 성공. 전체 백엔드 테스트 단계는 요청대로 skipped. 공개 파일 9개와 GitHub digest/SHA256SUMS 일치, 실제 다운로드 JAR 크기·SHA256 및 고정 공개키 Ed25519 매니페스트 서명을 검증했다. GitHub latest는 v0.6.1이다.
- 추가 실제 기능 시험: 격리된 임시 앱에서 패스키 등록·로그인, 동의 없는 베타 요청 거부, UI에서 베타 선택·동의, 실제 GitHub 다운로드·정확한 버전 staging·서명·해시 검증을 통과했다. 계정 파일·자동 업데이트 비활성화 설정이 유지됐다. 운영 앱과 프로필은 변경하지 않았다.
