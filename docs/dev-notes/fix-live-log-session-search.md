상태: 로그 기능·브라우저16개·TS/Vite 검증 완료, beta32 통합 대기
# fix/live-log-session-search
- beta31 배포 계열 + 검증된 미출시 Mixin 분석창 닫기 수정을 기반으로 작업한다. 운영 월드·게임 버전은 변경하지 않는다.
- 현재 세션 live.log와 전체 누적 console.log를 분리한다. 같은 Minecraft PID/시작 시각의 제어 계층 재연결에서는 live.log를 유지한다.
- 열린 파일 전체를 제한된 백그라운드 작업으로 검색하고, 진행률·검색 결과 페이지·취소·질의 변경 시 이전 작업 정리를 지원한다. 원문은 추가 복제하지 않고 결과 위치만 메모리에 보관한다.
- 검색은 현재 표시 제외 규칙과 오류·경고 조건을 적용한다. 로거/키워드로 숨긴 헤더의 스택 연속 행도 제외한다. 전체 일치 수를 계산하며 메모리 보호를 위해 결과 위치는 최초 100,000개까지 보관하고 초과 시 화면에 안내한다.
- 권한: 조회 사용자가 자기 검색만 생성/조회/취소할 수 있다. 실행기 검색 작업은 읽기 전용으로 취급하며 파일 수정 예약을 만들지 않는다. 관리웹과 실행기를 모두 업데이트해야 한다.
- 선커밋 후 테스트 계획: 120만 줄 마지막 구간 검색, 숨긴 로거·키워드·스택/DEBUG 조건, gzip, 취소/파일 교체, 세션 재연결/새 실행 및 레거시 마이그레이션, 브라우저 전체 검색 진행/페이지/취소/필터 재검색, 기존 Mixin 닫기/자동 스크롤 회귀, TS/Vite·대상 백엔드·패키징 검사.
- 사용자가 추가한 모드로더/Minecraft 버전 변경은 별도 작업 브랜치에서 이어서 통합한다.

## 검증 결과
- 선커밋 후 LogSearchTest 6개와 기존 LogFiles/RemoteConsole 회귀 통과. 120만 줄 파일에서 1,199,999번째 줄을 스크롤 없이 검색했다.
- 관련 브라우저16개(검색2·자동스크롤5·Mixin닫기9) 통과, TS/Vite 빌드 성공.
- 초기 Playwright CLI 경로 오류는 프로젝트에 잠긴 실행 파일을 사용해 해결했다. 제품 실패로 계산하지 않는다.
- 후속 버퍼 I/O·검색 소유권·구형 실행기 기능 협상 보완은 의존 브랜치 feat/server-runtime-updates에서 검증·통합한다.
