# fix/mixin-dialog-close

- 최신 원격 확인, 게시된 v0.7.0-beta.31 기반 단독 수정. 다른 브랜치/운영 서버는 변경하지 않는다.
- 원인: 닫기가 큰 본문 맨 아래에만 존재하고 Escape/배경 닫기 없음. GroupedConsole.expandDetail의 비동기 완료가 닫은 창을 다시 여는 경합. 모든 원문/프레임/Mixin을 한 번에 렌더링.
- 공통 portal 모달: 상단 고정 닫기·스크롤 본문, Escape/배경/기존 뒤로가기, 포커스 복구/키보드 포커스 유지, 모바일 높이 대응.
- 창 닫기/대상 변경/언마운트 시 AbortController 취소. fetch/worker 파싱 전후 취소 검사로 늦은 완료·오류·다음 요청을 무시한다.
- 원문은 손실 없이 32Ki 문자 구간, 프레임10개/페이지, Mixin100개/페이지로 표시. 모드·config 그룹 유지, 전체 원문은 모든 페이지로 조회 가능.
- 커밋 후 검증 계획: TS/Vite 빌드, 새 브라우저9개(큰 블록/프레임×desktop/mobile4, 요청 중 버튼/Escape/Back/배경4, worker 파싱 중 닫기1), 기존 console-follow5. 닫기 화면 내 위치·응답, DOM 개수 제한, 원문 다음 페이지 일치, 오래된 응답 재열림 방지/새 창 로딩 상태 초기화를 검사한다.
- 전체 backend suite·다른OS·운영 배포/서비스 재시작은 이번 범위가 아니다. 릴리즈는 아직 요청받지 않았다.
