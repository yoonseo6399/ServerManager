상태: 완료 — 관련 백엔드 33개·브라우저 4개·실제 부트스트랩 롤백 통과
# feat/runner-release-picker
- 단독 구현. 전체 테스트·다른 OS 검증은 사용자 지시로 생략한다.
- 관리 웹 실행기 카드에서 현재 채널·릴리즈 선택·베타 동의·대상 버전·다운로드 진행률·대기/실패 로그를 제공한다.
- 구형 실행기에는 먼저 최신 안정판으로 원격 업데이트하는 경로를 안내한다. 연결마다 선택/롤백 기능을 새로 협상하고 미지원 실행기에 요청을 보내지 않는다.
- 관리 앱과 실행기에서 낮은 안정판 선택은 별도 롤백 동의가 필요하다. 기존 게임 상주 서비스와 호환되는 0.6.0 이상 안정판으로 제한한다. 프로필·월드를 과거 상태로 복원하는 기능은 아니다.
- 새 부트스트랩 설치판이 필요하다. 기존 JAR 업데이트로 부트스트랩을 바꾸지 않으며 지원하지 않는 설치판에서는 롤백을 막는다.
- 기존 Qwen 시험판에서도 돌아올 수 있도록 같은 기능을 새 베타에도 통합할 예정이다. 이미 게시된 0.7.0-beta.1은 바꾸지 않는다.
- 검증: 관련 백엔드 33개·브라우저 4개 통과, 프런트엔드/bootJar 빌드 통과. 실제 관리 앱·실행기 부트스트랩의 낮은 안정판 적용/재시작 유지/변조 거부/승인 없는 다운그레이드 거부/실패 복구를 임시 서명 패키지로 확인했다.
- 실제 관리 웹의 패스키 로그인·낮은 안정판 동의 거부·GitHub 다운로드·정확한 대상 staging/서명/해시·계정/자동 설정 보존을 격리 프로필에서 확인했다. 실제 게임·타 OS·운영 설치는 하지 않았다.
