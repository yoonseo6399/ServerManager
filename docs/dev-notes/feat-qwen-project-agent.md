상태: 구현 완료 — 관련 기능 테스트 32개 통과, 테스트용 베타 릴리즈 준비
# feat/qwen-project-agent
- 사용자 최신 지시: 서브에이전트를 사용하지 않는다. 전체 테스트는 생략하고 변경 기능만 검증한다.
- 기존 `/agent`는 Qwen 프로젝트 에이전트로 통합하고 기존 클라우드 기능은 `/cloud-agent`로 보존한다.
- 추론은 설정한 Ollama 실행 컴퓨터, 도구는 관리 앱 OS 사용자 권한으로 실행한다. 임의 폴더·프로그램을 다루므로 UI에서 실행 위치와 정확한 요청을 표시한다.
- 독립된 도구 없는 새 Ollama 대화가 매 도구 요청을 검토한다. 명시적 승인이 기본이며 자동 모드는 낮은 위험으로 허용된 요청만 자동 진행하고 나머지는 사용자에게 묻는다. 검토 실패/거부는 실행하지 않는다.
- 운영 Minecraft/Discord/설정에 자동 적용하지 않는다. 실제 Discord 및 실제 모델 검증 여부를 마지막에 구분한다.
- 개인 모델 기본값, 기본 Thinking, 비공개 프로젝트 채널과 문맥, 턴별 출력, 프로젝트 도구, 별도 감시 대화, 사용자 이름·ID 전달을 구현했다. 사용법과 제한은 docs/qwen-project-agent.md 참조.
- 관련 자동 테스트 32개 통과. 실제 14B 임시 파일 수정·독립 검토·승인 및 Thinking 스트림 테스트 각각 통과. 프런트엔드와 bootJar 빌드 통과. 실제 Discord·30B·타 OS·전체 테스트는 미실행.
