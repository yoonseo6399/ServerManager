# fix/console-follow-scroll

- 기준: v0.7.0-beta.27. 기본 블록 콘솔이 매 조회마다 강제로 끝으로 이동하던 문제 수정.
- 위로 스크롤하면 자동 추적을 즉시 중지하고 현재 300줄 구간 시작점을 고정. 새 로그가 많이 생겨도 읽는 구간을 교체하지 않음.
- 실시간 구간에서 맨 아래로 돌아오면 추적 재개. 과거 구간은 명시적으로 최신으로 이동하기 전까지 유지.
- 블록/원문 보기 모두 `아래로 이동` 버튼 추가. 원문 보기의 56px 정지 임계값과 상태 반영 지연도 개선.
- 프로덕션 서비스 재시작, 실제 서버 조작, 릴리즈는 이번 작업에 포함하지 않음.

## 커밋 후 테스트 계획
- TypeScript/Vite 프런트엔드 빌드.
- Playwright: 블록/원문 × 데스크톱/모바일에서 24px 위로 이동 후 350줄 추가 중 위치 보존, 맨 아래에서 추적 재개, 아래로 이동 버튼으로 최신 복귀.
- 과거 구간 조회 중 신규 로그가 생겨도 구간 유지.
- 기존 실시간 크래시 표시 4개 회귀 시나리오. 전체 테스트는 생략.

## 1차 검증
- 프런트엔드 빌드 통과. 브라우저 9개 중 원문 2개·과거 구간 1개·실시간 크래시 4개 통과.
- 블록 보기 2개에서 초기 위치 검증 실패. 화면 밖 블록은 content-visibility로 높이 계산이 생략되므로 테스트가 실제 로그 영역으로 이동해 충분한 스크롤 범위를 확보한 뒤 검증하도록 보완. 원인 및 재검증 결과 확인 예정.

## 추가 수정 및 재검증 계획
- 실제 화면에서 위치 고정은 통과했으나 최신 구간으로 복귀할 때 블록의 `content-visibility:auto`가 임시 높이(150px)를 사용해 끝 위치를 잘못 계산하고 추적이 중지되는 결함 확인.
- 이미 300줄로 제한된 블록 구간은 실제 높이로 레이아웃하도록 변경. 5개 스크롤 기능 테스트를 재실행하고 프런트엔드 빌드를 재확인.
