# fix/music-autoplay-skip

- 기준: 게시된 `v0.7.0-beta.26` (924dca8). 독립 워크트리, 단독 작업.
- 원인: `skip()`은 대기열 전환만 수행하고, 자동재생 예약은 `FINISHED` 이벤트에서만 수행했다. `STOPPED`로 끝나는 마지막 곡의 다음 버튼은 재생을 중단했다.
- 수정: 대기열이 비면 자동재생 후보를 요청한다. 건너뛴 곡은 이번 선택에서 제외하며 다른 후보가 없으면 안내한다. 대기열 우선, 자동재생 끄기, 반복 재생 건너뛰기, 중지 시 지연 응답 무효화를 유지한다.
- 가중치: 서버별 기존 완주 기록에 `skips`(기본 0)를 저장. 기본 가중치에 `1 / (1 + min(skips, 9))`를 곱한다. 첫 건너뛰기는 절반, 최저 10%. 완주 횟수는 보존하고, 완주 기록 없는 곡은 건너뛰기만으로 후보에 등록하지 않는다. 기존 JSON은 기본값으로 호환된다.
- Discord 버튼과 `/music skip`은 같은 함수를 사용하므로 함께 반영된다.

- `DiscordMusicLibraryStoreTest`: 저장·재로드, 서버별 격리, URL 정규화, 다음 완주 시 건너뛰기 보존, 기존 JSON 호환.
